语音合成常见问题

XML 标签如何使用

XML 标签用于控制停顿、发音、音量、语速、语调和音子边界等合成效果，具体用法请参阅 xml 标签 和 SSML 标签。

什么是音子边界信息

文本经过分析后会生成音子序列。音频分片返回后，服务会计算音子边界信息。时间单位为秒，每个小句的音频从本句起点重新计时。

什么是定制库

定制库是根据指定话术和发音人的录音制作的音频资源。当合成文本命中定制话术时，服务直接返回对应的定制音频。

常见流程是：提交话术文本、完成录音、加工生成资源文件，再配置到对应 TTS 音库中。

API 或 SDK 可以调节哪些参数

通常支持音量、语速和语调调节，具体参数以所使用的接口或 SDK 文档为准。

单次可以合成多少文字

短文本合成单次输入建议不超过 300 个汉字，超过接口限制时会返回参数错误；长文本场景请使用长文本合成接口。

合成音频支持哪些格式

可根据接口配置输出 8000Hz 或 16000Hz、16bit、单声道的 PCM、WAV 或 MP3 音频，实际支持范围以对应接口说明为准。
