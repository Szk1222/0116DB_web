音频格式说明

语音识别服务对音频编码、采样率、位深和声道有明确要求。提交识别前请确认音频参数与接口参数一致，否则会影响识别效果或导致请求失败。

音频要求

项目要求说明
支持音频格式wav、pcm旧站音频格式说明中，一句话识别和实时识别推荐使用 WAV 或裸 PCM 音频。
音频采样率8000Hz、16000Hz语音数据采样率需要与请求参数保持一致。高于 16000Hz 的音频建议降采样后提交。
位深16bits常用格式为 16bit 小端序，每次采样使用 2 字节保存。
声道单声道除录音文件识别等特殊能力外，识别服务通常要求单声道音频；双声道音频需先转换为单声道。

音频文件转换工具 ffmpeg

FFmpeg 是一款可进行音视频处理的开源软件。旧站文档提供了常见音频格式转换命令，以下命令统一转换为 16000Hz、16bit、小端序、单声道音频。

wav 转 pcm

ffmpeg -i input.wav -acodec pcm_s16le -ac 1 -ar 16000 -f s16le output.pcm

mp3 转 pcm

ffmpeg -i input.mp3 -acodec pcm_s16le -ac 1 -ar 16000 -f s16le output.pcm

mp3 转 wav

ffmpeg -i input.mp3 -acodec pcm_s16le -ac 1 -ar 16000 output.wav

参数解释

参数说明
-i输入文件。
-acodec音频编码器或解码器；pcm_s16le 表示 16bit 小端序 PCM。
-ac声道数；1 表示单声道。
-ar采样率；示例中使用 16000。
-f设置输出音频文件格式；裸 PCM 输出常用 s16le。

注意事项

  • 如果音频文件是 8000Hz，不要简单升采样到 16000Hz 后提交，应选择匹配 8000Hz 的识别参数。
  • WAV 是文件封装格式，音频数据本身仍可能采用 PCM 或其他编码；提交前应确认编码格式被服务支持。
  • 转换后的音频建议先抽样试听或检查文件信息，确认采样率、位深、声道与接口参数一致。
