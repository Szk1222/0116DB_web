语音识别音频

音频要求

  • 支持音频格式：wav，pcm
  • 音频采样率：8000Hz，16000Hz
  • 位深：16bits
  • 声道：单声道

音频文件转换工具ffmpeg

FFmpeg 是一款可以进行音视频处理的开源软件，具体功能可参考官网http://ffmpeg.org/，这里仅提供音频格式转换的方法
wav转pcm
ffmpeg -i input.wav -acodec pcm_s16le -ac 1 -ar 16000 -f s16le output.pcm
mp3转pcm
ffmpeg -i input.mp3 -acodec pcm_s16le -ac 1 -ar 16000 -f s16le output.pcm
mp3转wav
ffmpeg -i input.mp3 -acodec pcm_s16le -ac 1 -ar 16000 output.wav

参数解释：

  • -i：输入文件
  • -acodec：音频编码器和解码器
  • -ac：通道数
  • -ar：采样率
  • -f：设置音频文件格式
