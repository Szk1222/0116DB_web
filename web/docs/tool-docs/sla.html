服务等级协议SLA

协议生效日期：2021年3月1日

本协议包含本服务的术语和定义、服务可用性、成功率等级指标、免责条款等相关内容。请您务必审慎阅读、充分理解各条款内容，除非您已充分阅读、完全理解并接受本协议所有条款，否则，请您不要购买本服务。您的购买、使用等行为或者您以其他任何明示或者默示方式表示您同意本协议的约束。

定义

  • 1.1 标贝开放平台提供的智能服务：

    标贝开放平台为您提供的语音识别、语音合成、语音拓展等接口调用服务，包含一句话识别、长语音识别、录音文件识别、在线合成、离线合成、长文本合成等以及以后上新的产品服务，具体以您使用的服务为准。

  • 1.2 服务周期：

    一个服务周期为一个自然月。

  • 1.3 服务周期内不可用分钟数：

    在某一分钟内，只有在您持续通过 API 或 SDK请求本服务的所有请求均返回内部错误的情况下，该分钟才计入服务周期内不可用分钟数；如在某一分钟内通过API 或 SDK请求本服务的请求仅部分或未完全返回内部错误时，则视为该分钟内的本服务均是可用的，不计入服务周期内不可用分钟数；同时，如果您某一分钟内对本服务的请求数为零，此分钟也不计入不可用分钟数。在一个服务周期内服务不可用分钟数之和即为服务周期内不可用分钟数。

  • 1.4 退避要求：是指发生错误后，客户应当等待一段时间后再发出下一个请求。也就是说，在发生第一个错误后，最短退避间隔为 1 秒；而对于每个连续发生的错误，退避间隔时长以指数方式增加，最长为 32 秒。
  • 1.5 失败请求：因服务故障导致的用户正常请求未能返回正常结果或用户正常请求得到的返回结果完全不可用（错误率达到50%以上），但不包括因客户原因导致的失败请求，例如：
    • 1.5.1 因客户端网络异常引起的响应延迟或超时等请求。
    • 1.5.2 因客户端调用逻辑不符合接口规范、用户操作行为不当引起的失败请求。
    • 1.5.3 未通过SDK身份校验、接口鉴权失败、参数校验、权限校验等失败请求。
    • 1.5.4 因音频格式、文本编码等不符合要求而导致结果错误的请求。
  • 1.6 有效请求：符合文档要求的接口调用请求，但不包括未通过身份验证和鉴权失败的请求、开发文档中的错误参数等请求。
  • 1.7 错误率：( 失败请求数 / 有效请求数 ) * 100% ，重复的相同请求不计入错误率，除非它们符合退避条件。
  • 1.8 不可用时间：是指错误率>=5%的时间，不可用时间根据服务端的错误率进行衡量。不可用时间段是指持续不可用一分钟或更长时间的时间段。少于一分钟的零散或间歇不可用时间不会计入任何不可用时间段。
  • 1.9 服务周期内总分钟数：按照服务周期内的天数 * 24（小时）* 60（分钟）来计算。

服务可用性

  • 2.1 服务可用性计算方式

    服务可用性 =（1 - 服务周期内不可用分钟数/服务周期内服务总分钟数）x 100%

  • 2.2 服务可用性标准

    标贝开放平台提供的服务可用性不低于99.00%，具体详见服务可用性承诺。

    长语音识别/录音文件识别 99.00%
