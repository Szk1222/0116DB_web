服务等级协议 SLA

本协议说明智能语音服务的可用性定义、指标计算方式、服务承诺和免责范围。

适用服务

适用于平台提供的语音识别、语音合成及相关接口调用服务，具体以用户实际开通和使用的服务为准。

术语与计算

  • 服务周期：一个自然月。
  • 有效请求：符合接口文档要求并通过鉴权、参数校验的正常请求。
  • 失败请求：因服务端故障导致有效请求未返回正常结果的请求。
  • 错误率：失败请求数除以有效请求数，再乘以 100%。重复请求仅在符合退避要求时计入统计。
  • 不可用时间：服务端错误率达到 5% 或以上，并持续 1 分钟或更长时间的时间段。
  • 发生连续错误时，建议采用指数退避，首次等待至少 1 秒，最长等待 32 秒。

可用性承诺

服务可用性计算方式：

服务可用性 = (1 - 不可用分钟数 / 服务周期总分钟数) x 100%
服务类型可用性承诺
一句话识别、在线合成、长文本合成99.90%
长语音识别、录音文件识别99.00%

不计入范围的情况

  • 客户端网络异常、设备故障、调用逻辑错误或用户操作不当。
  • 请求未通过鉴权、参数校验、权限校验，或音频格式、文本编码不符合要求。
  • 计划内维护、升级、故障演练及安全处置。
  • 第三方网络、设备、软件、不可抗力或超出服务能力上限造成的不可用。

服务支持

发生持续异常时，请保留请求时间、接口、错误码、日志标识和调用量等信息，并通过平台客服渠道提交问题。
