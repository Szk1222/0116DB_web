计费构成

服务 计费方式 补充说明
一句话识别 按照调用次数计费 按次数计费的，返回失败的调用不计入次数，单次60秒内。
长语音识别 按照处理语音时长计费 按时长计费的，累加每次调用的语音时长（按秒向下取整，如本次发送的语音长度为30.8秒，则记为30秒）
录音文件识别 按照录音时长计费 按时长计费的，累加每次调用的语音时长（按秒向下取整，如本次发送的语音长度为30.8秒，则记为30秒），单次长段音频5小时以内。
双声道文件根据通道数和时长计费，即声道数×音频时长。
短文本合成 按照调用次数计费 按照语音合成的调用次数计费，每调用成功一次消耗一次。接口调用传入的字符数（UTF-8编码：1个汉字、英文字母、全半角标点符号均算1个有效字符）的限制为：1次请求最多传入300个汉字，按照每100个汉字计费1次，依此类推。
离线合成（普通版） 按照使用个数计费 按照可安装个数进行计费。
离线合成（精品版） 按照使用个数计费 按照可安装个数进行计费。
长文本合成 按照合成字数计费 按照合成字数进行计费。
声音复刻 模型：按照训练个数计费
合成：按照使用量计费		 模型个数与合成用量为两个独立的授权，购买复刻模型的同时还需购买合成用量。
合成：方式
①-按照合成次数计费，接口调用传入的字符数（UTF-8编码：1个汉字、英文字母、全半角标点符号均算1个有效字符）的限制为：1次请求最多传入300个汉字，按照每100个汉字计费1次，依此类推。
②-按照并发（每年/每路）计费，无次数限制。
声音转换 按照处理语音时长计费 按时长计费的，累加每次调用的语音时长（按秒向下取整，如本次发送的语音长度为30.8秒，则记为30秒）。
声纹识别 按照调用次数计费 按次数计费的，返回失败的调用不计入次数，针对比对验证的次数进行计费，1:N识别比对按照接口返回次数计算。
离线声音转换 按照使用个数计费 按照可安装个数进行计费。
声音理解 按照调用次数计费 按次数计费的，返回失败的调用不计入次数，单次5-60秒。
语音评测 按照调用次数计费 按次数计费的，返回失败的调用不计入次数，单次3-60秒。

并发线路增额资费

商品规格 收费说明 补充说明
超额并发路数线路资费 超出采购额定线路，需要额外增加线路需求 1.并发数计算：并发数指同一个账号同时在处理的请求数。一般语音请求的处理都会延续一段时间。（例如，您新建一个语音合成请求，持续发送语音数据给服务端，这时并发数就是1；在该请求处理的同时，又新建了一个请求发送语音数据，这时服务端同时处理该账号的2个请求，并发数就变为2 ）。
注：并发和用量为两个单独的授权，在您购买并发前请确保您有足够的用量。
