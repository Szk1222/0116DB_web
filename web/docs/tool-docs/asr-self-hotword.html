自学习 - 热词

热词用于优化语音识别中专有词汇的识别效果。创建并发布热词组后，在语音识别 API 或 SDK 请求中传入热词组 ID，即可让识别服务优先参考该词表。

功能介绍

在语音识别 ASR 服务中，通用词汇通常识别效果较好；但在部分专有业务领域中，人名、地名、公司名、领域专有词等可能默认识别效果不佳。通过 ASR 自学习引擎配置热词，可提升这些词汇在识别结果中的准确率。

热词适合处理短词、专名、术语等词级别优化需求。如果词条过长、接近句子或段落，建议使用个性化模型。

使用限制

项目说明
生效时间保存发布后通常秒级生效。
词组数量单个应用的语音识别服务下最多可创建 10 个词组。
词条数量每个词组最多 300 个词。
词条格式每行一个热词，以回车键区分。
词条长度单个词长度不超过 10 个字；超出限制建议使用个性化模型。
文件格式UTF-8 编码的 txt 文件，不能包含标点和特殊字符。
适用服务一句话识别、实时长语音识别、录音文件识别。
语言类型中文普通话、粤语、英文。
采样率模型8K、16K 采样率。
创建方式通过开放平台控制台创建和修改。

特别注意

  • 常见通用词汇不建议加入热词，加入过多通用词可能降低专有词汇识别率。
  • 使用热词前，请先确认音频清晰度和质量达标；普通人听一遍音频应能正确辨识内容。
  • 热词不建议过长，不支持标点符号。
  • 中文语言类型中的数字需要用汉字代替，例如 9.8元 写作 九点八元。
  • 英文语言类型中的数字需要用英文代替，例如 9.8 meters 写作 nine point eight meters。

使用方法

  1. 登录开放平台并创建应用。
  2. 进入语音识别下的自学习工具页面。
  3. 点击新增热词组，上传热词 TXT 文件并保存发布。
  4. 获取热词组 ID。
  5. 调用语音识别 API 或 SDK 时传入该热词组 ID，测试识别效果。

识别调用传参

控制台完成热词创建后，在后续语音识别请求中传入 hotwordid 即可使用该热词组。

参数类型说明
hotwordidstring热词组 ID。适用于一句话识别、实时长语音识别、录音文件识别等支持热词的请求。
{
  "asr_params": {
    "audio_format": "wav",
    "sample_rate": 16000,
    "hotwordid": "HOTWORD_GROUP_ID"
  }
}
