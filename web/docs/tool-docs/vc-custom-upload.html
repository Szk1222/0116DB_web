定制模型 - 平台上传复刻音频

平台上传复刻音频适用于不通过代码接入、直接在开放平台控制台创建声音复刻模型的场景。完成录音或上传后，平台会进行模型训练，训练成功后产出声音模型 ID，可用于后续语音合成调用。

使用流程

  1. 登录开放平台并创建或进入已有应用。
  2. 在应用服务中选择声音复刻下的定制模型能力。
  3. 按页面提示获取朗读文本，并准备安静环境下录制的音频。
  4. 上传复刻音频，确认音频格式、采样率、位深和有效时长符合要求。
  5. 提交训练任务后等待模型训练完成。
  6. 训练成功后获取声音模型 ID，并将该 ID 作为合成接口或 SDK 中的 voice_name 使用。

音频要求

项目要求
音频格式wav、pcm
采样率16000Hz
位深16bits
声道单声道
有效时长建议不小于 3 分钟；接口侧会结合识别出的字数进行判定。
语言中文

录音建议

  • 尽量在安静环境录制，避免明显背景噪声、回声和突发声。
  • 人声音量不要过小，录制过程中保持音量稳定。
  • 朗读内容应完整、清晰，避免长时间停顿、漏读和错读。
  • 训练成功后请保存模型 ID；合成体验或正式调用时需要使用该 ID。

训练结果

字段说明
modelId声音模型 ID。训练成功后可作为 voice_name 调用语音合成。
modelStatus模型状态。常见状态包括训练中、训练失败、训练成功。
reason训练失败或异常时的原因说明。

后续调用

模型训练成功后，可通过两种方式体验或使用该声音：

  • 使用声音模型 ID 调用语音合成 RESTful API，适合短文本合成和服务端调用。
  • 集成语音合成 SDK，适合客户端播放、流式返回和更完整的合成控制。
