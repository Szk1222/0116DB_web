声音转换 Android SDK

声音转换 Android SDK 用于在 Android 端快速接入变声能力，内置录音流程，也支持调用方传入音频字节流完成转换。

下载与依赖

SDK 与示例 Demo 下载地址：https://github.com/data-baker/BakerAndroidSdks

在工程根目录 build.gradle 中加入 JitPack 仓库：

allprojects {
  repositories {
    maven { url 'https://jitpack.io' }
  }
}

在主 Module 中加入依赖：

dependencies {
  implementation 'com.github.data-baker.BakerAndroidSdks:bakerbasecomponent:2.0.11'
  implementation 'com.github.data-baker.BakerAndroidSdks:bakerhttp:2.0.11'
  implementation 'com.github.data-baker.BakerAndroidSdks:voiceconvert:2.0.11'
  implementation 'com.squareup.okhttp3:okhttp:4.2.2'
  implementation 'com.google.code.gson:gson:2.8.6'
}

权限与混淆

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />

Android 6.0 及以上需要动态申请 RECORD_AUDIO 权限。如需明文网络访问，在 application 节点增加：

android:usesCleartextTraffic="true"

混淆配置：

-keep class com.databaker.voiceconvert.** { *; }
-keep class com.baker.sdk.http.**{*;}
-keep class com.baker.sdk.basecomponent.**{*;}

关键类

类名说明
VoiceConvertManager声音转换业务处理类，全局只需一个实例。
VoiceConvertCallBack声音转换业务回调类，返回转换进度、原始数据、转换结果和错误信息。回调运行在子线程。

调用流程

  1. 实例化 VoiceConvertManager。
  2. 调用 init(Context context, String clientId, String clientSecret, AuthCallback authCallback) 初始化 SDK。
  3. 设置目标音色、VAD、音频对齐等参数。
  4. 按场景选择麦克风录音转换或字节流转换。
  5. 在 VoiceConvertCallBack 中接收状态、转换结果或错误信息。
  6. 不再使用时调用 release() 释放资源。
VoiceConvertManager convertManager = new VoiceConvertManager();
convertManager.init(context, clientId, clientSecret, authCallback);
convertManager.setVoiceName("Vc_jiaojiao");
convertManager.setVadEnable(true);
convertManager.setAudioAlign(true);

转换场景

麦克风实时转换

  1. 确保应用已取得录音权限。
  2. 通过 VoiceConvertManager 设置参数。
  3. 调用 startFromMic(callBack) 开启录音转换。
  4. 在回调中接收状态、转换结果、原始录音数据或错误信息。
  5. 调用 stopRecord() 结束录音转换。
  6. 根据 onAudioOutput() 中的 isLast 判断转换数据是否完整返回。

音频字节流转换

  1. 通过 VoiceConvertManager 设置参数。
  2. 调用 startFromBytes(callBack) 通知 SDK 准备转换。
  3. 在 onReady() 回调后，多次调用 sendAudio(byte[] data, boolean isLast) 输入待转换音频。
  4. 单次数据建议固定为 5120 字节；最后一片可以为其他长度，并且 isLast=true。
  5. 前后两次 sendAudio 调用间隔不要超过 10 秒。

方法说明

方法说明
init()初始化 SDK，必须先调用。
startFromMic()使用 SDK 内部录音进行声音转换。
stopRecord()结束录音转换。
startFromBytes()开启调用方自有音频数据转换。
sendAudio()在 onReady() 后发送音频字节流。
setVoiceName()设置目标声音模型名称，默认 Vc_jiaojiao。
setVadEnable()设置是否开启服务端 VAD，默认 false。
setAudioAlign()设置输出音频是否与输入音频对齐，默认 false。
release()释放 SDK 资源。

回调说明

回调说明
onReady()SDK 已准备好，可以开始发送音频数据。
onAudioInput()返回原始录音或输入音频数据。
onAudioOutput()返回转换后的音频数据，包含是否最后一包标记。
onError()返回错误码、错误信息和 traceId，出现错误后本次转换任务中断。
