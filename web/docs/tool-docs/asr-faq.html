语音识别常见问题

排查识别错误

  1. 检查采样率、位深、声道、格式和文件大小，确认与所选模型及服务场景匹配。
  2. 播放音频确认人声是否清晰，是否存在吞音、语速过快、重口音、方言或明显噪声。
  3. 查看波形、能量和频谱，确认音量没有过小或削波，频段信息完整。
  4. 确认控制台项目使用的模型支持当前音频采样率和业务场景。

音频格式要求

  • 一句话识别和实时长语音识别：无压缩 PCM 或 WAV，8KHz 或 16KHz，16bit，单声道。
  • 录音文件识别：支持单声道或双声道 PCM、WAV、MP3；上传文件和通过 URL 提交时有不同的大小限制，以接口文档为准。

为什么识别率不高

常见原因包括音频质量较差、音量或格式不符合要求、模型与采样率不匹配、方言或重口音训练覆盖不足，以及噪声被送入识别引擎。

建议先完成音频质量和模型参数排查。吞音、听不清或原始音频辨识度低的情况，无法仅通过识别参数完全修复。

人声或环境噪声被识别怎么办

  • 人声噪声可能被模型判断为有效语音，建议改善录音距离、环境和麦克风配置。
  • 非人声噪声较多时，可收集代表性噪声样本，联系技术支持评估模型优化方案。

准确率问题需要提供哪些信息

建议同时提供接口类型、模型、采样率、音频格式、请求时间、错误码、日志标识和脱敏后的问题样例，便于定位。
