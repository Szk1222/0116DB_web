声音转换 iOS SDK

声音转换 iOS SDK 用于在 iOS 端接入实时声音转换和文件声音转换能力，支持麦克风录音转换，也支持传入音频文件路径进行转换。

下载与兼容

SDK 与示例 Demo 下载地址：https://github.com/data-baker/BakerIosSdks

  • 系统版本：iOS 9.0 及以上。
  • CPU 架构：arm64、arm64e、armv7、armv7s。
  • 权限配置：在 Info.plist 中添加 Privacy - Microphone Usage Description。

音频要求

  • 音频编码：pcm。
  • 采样率 / 位深：16000Hz / 16bit。
  • 声道：单声道。
  • 语言：中文普通话。

集成 SDK

通过 CocoaPods 集成：

pod 'DBAudioSDK/DBVoiceTransferKit', 'SDK_VERSION'

SDK_VERSION 为实际接入版本号。接入后导入声音转换类头文件：

#import "DBVoiceTransferUtil.h"

调用流程

实时声音转换

  1. 实例化 DBVoiceTransferUtil，调用 setupClientId:clientSecret:block: 完成鉴权。
  2. 配置目标音色、播放开关、回调代理等转换参数。
  3. 调用 startTransferNeedPlay: 开始转换，SDK 会使用麦克风录音。
  4. 通过 DBTransferProtocol 接收转换结果。
  5. 调用结束方法关闭麦克风和服务端连接。

声音文件转换

  1. 鉴权流程同实时声音转换。
  2. 配置声音转换参数。
  3. 调用文件转换方法，传入声音文件路径，并指定是否需要播放。
  4. 转换完成或取消时，关闭服务端连接。

调用代码示例

[[DBVoiceTransferUtil shareInstance] setupClientId:clientId
                                    clientSecret:clientSecret
                                           block:^(NSString * _Nullable token, NSError * _Nullable error) {
  if (error) {
    NSLog(@"获取 token 失败:%@", error);
    return;
  }
}];

DBVoiceTransferUtil *transfer = [DBVoiceTransferUtil shareInstance];
transfer.log = YES;
transfer.voiceName = @"Vc_jiaojiao";
transfer.delegate = self;

// 开始实时转换
[transfer startTransferNeedPlay:YES];

参数说明

参数 / 属性说明
clientId应用授权 ID。
clientSecret应用授权密钥。
voiceName目标声音模型名称，例如 Vc_jiaojiao。
delegate设置 DBTransferProtocol 回调代理。
log是否开启 SDK 日志。
needPlay是否需要 SDK 内部播放转换后的音频。

DBTransferProtocol 回调

回调说明
转换状态回调返回当前转换流程状态。
音频数据回调返回转换后的音频数据，可用于播放或写入文件。
结束回调提示本次转换已结束，可释放相关资源。
错误回调返回错误码、错误信息和追踪信息，本次转换任务中断。
