离线声音转换发音人列表

离线声音转换支持在设备端使用的目标音色，所有音色支持 16K 采样率。

名称voice name 参数（首字母大写）支持采样率（Hz）

使用说明

  • 调用 SDK 前先完成授权和初始化。
  • 每次转换前设置目标音色名称；未设置时默认使用 Vc_luoli。
  • 输入音频使用 PCM 格式时，应使用 16KHz、单声道、16bit 参数。
