标贝开放平台服务协议

本协议用于说明平台服务的使用条件、双方权利义务、数据与知识产权责任，以及服务变更和争议处理规则。

总则

  • 使用者在勾选同意或实际使用平台服务后，视为已阅读、理解并接受本协议。
  • 如不同意本协议或后续修改内容，请停止访问和使用相关服务。
  • 平台可根据业务变化更新协议，并通过平台页面公布最新版本；继续使用服务即表示接受更新后的内容。

服务与账户

  • 平台向开发者提供网站展示的产品、接口、SDK 及相关技术支持，具体能力以已开通的服务为准。
  • 开发者应按照注册流程提供真实、准确、完整的信息，并妥善保管账户、密码、令牌和密钥。
  • 账户仅限开发者自身使用，不得转让、出租、出借或以其他方式交由第三方使用。
  • 服务价格、免费额度、有效期和使用限制以当时的平台页面及订单信息为准。

使用规范

  • 开发者应遵守适用法律法规、平台规则和产品文档，不得利用服务从事违法、欺诈、侵权、恶意推广或扰乱平台运行的活动。
  • 开发者应确保上传的文本、音频、图片、数据及其他素材来源合法，并已取得必要的授权。
  • 不得绕过接口鉴权、伪造请求、攻击平台、传播恶意程序、抓取非公开数据或超出授权范围使用服务。
  • 应用应向自身用户清晰说明数据收集、使用和删除方式，并承担应用内容及运营行为的责任。

数据与知识产权

  • 开发者对提交的数据及使用数据产生的内容承担合法性、准确性和安全保护责任。
  • 平台及其合法权利人拥有平台软件、接口、文档、商标、技术资料和运营数据的相关权利。
  • 未经书面授权，不得复制、传播、反向工程、转售平台服务，或删除、隐藏平台的权利声明。
  • 双方因履行协议获知的商业、技术和业务信息应承担保密义务。

服务变更、终止与责任

  • 平台可根据维护、升级、安全风险或业务调整，对服务进行变更、暂停或终止，并在合理范围内进行通知。
  • 因开发者违规、账户安全问题、错误调用、第三方网络或不可控因素造成的损失，由相应责任方承担。
  • 平台在适用法律允许的范围内，对间接损失、预期收益损失和开发者自身原因造成的损失不承担责任。
  • 协议终止后，保密、知识产权、责任承担和争议解决等依其性质应继续有效的条款仍然有效。

争议处理

双方应优先通过协商解决争议。协商不成时，按照协议约定的适用法律和管辖机构处理。
