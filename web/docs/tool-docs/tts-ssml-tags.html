SSML标记语言

概述

SSML是一种基于XML的标记语言，它的主要功能是为语音合成用户提供一种标准方法，在使用语音合成功能时，用户可以使用SSML控制语音合成的效果，主要功能如下：

基本功能

  • 音色
  • 文件类型
  • 采样率
  • 码率
  • 语速
  • 音调
  • 音量
  • 添加背景音乐
  • 背景音乐音量

个性化功能

  • 停顿时间<break>
  • 自定义文本结构<s>
  • 别名<sub>
  • 词组分词<w>
  • 读音更改<phoneme>
  • 添加提示音<soundEvent>
  • 选择指定场景读法<say-as>

注意

1. SSML标记语言和标贝XML标签不可混用。

2. 使用SSML标记语言后，以SSML标记语言选定参数为准，优先级高于接口请求参数。

3. 目前仅支持中文音色

4. 所有文本需放在<speak></speak>标签之内，且每个语音合成任务只能包含一个<speak></speak>标签。长文本合成可以含多个成对的<speak></speak>标签。当调用多个ssml标签时，文本中间不能有多余的空格。

5. 标签内的文字内容如果包含XML的特殊字符，需要做字符转义，常用的特殊字符对应关系如下：

  • "（双引号）对应：&quot;
  • '（撇号或单引号）对应：&apos;
  • &（表示和的符号）对应：&amp;
  • < （小于号）对应：&lt;
  • >（大于号）对应：&gt;

使用方式

发送请求给语音合成服务, http post请求头需要添加`Content-Type:application/json` , 请求body内容如下：

{
    "domain": "1",
    "access_token": "xxxxxxxxxxxxxxxxxxxx",
    "voice_name": "Jiaojiao",
    "language": "zh",
    "interval": "1",
    "version": "2",
    "text": "<speak>请找一个舒适的地方坐下<break time=\"500ms\"/>慢慢放松呼吸。</speak>"
}

基本功能

<speak>

  • 描述

    <speak>标签是所有待支持SSML标签的根节点。所有调用SSML标签的文本都要包含在<speak></speak>中。

  • 语法

            <speak>需要调用SSML标签的文本</speak>

  • 属性

    <speak>标签支持如下属性。

    参数说明 类型 是否必选 说明
    voice String 否 在合成时，指定线上可调用的发音人的名称代号，voice参数值，如”Jingjing”。
    优先级高于接口请求参数`voice_name`指定的发音人。长文本任务允许多个ssml标签使用不同的音色，接口处、标签内所选音色的采样率都需要保持一致，如果不一致会报错（音色支持采样率可查询语音合成-发音人列表 ）。
    audiotype String 否 在合成时，指定音频文件格式：
    优先级高于接口请求参数`audiotype`指定的文件格式。长文本任务在SSML标签中设置audiotype参数无效。
    可不填，不填时默认为3，表示mp3格式
    audiotype=3 ：返回16K采样率的mp3格式
    audiotype=4 ：返回16K采样率的pcm格式
    audiotype=5 ：返回8K采样率的pcm格式
    audiotype=6 ：返回16K采样率的wav格式
    audiotype=6&rate=1 ：返回8K的wav格式
    audiotype=7 ：返回8k8bit的alaw格式文件
    audiotype=8 ：返回8k8bit的ulaw格式文件
    audiotype=9&rate=1 返回8K采样率的mp3
    rate String 否 在合成时，指定音频的码率：
    优先级高于接口请求参数`rate`指定的码率。长文本任务在在SSML标签中设置rate参数无效。
    可不填，不填时默认为2，取值范围1-8，2以上的值仅针对返回MP3格式，对应的码率为：
    1 —— 8kbps
    2 —— 16kbps
    3 —— 24kbps
    4 —— 32kbps
    5 —— 40kbps
    6 —— 48kbps
    7 —— 56kbps
    8 —— 64kbps
    speed String 否 在合成时，指定音频的语速，在0～9之间（支持浮点值），不传时默认为5
    优先级高于接口请求参数`speed`指定的语速
    pitch String 否 在合成时，指定音频的音调，取值0～9之间，不传时默认为5，中语调
    优先级高于接口请求参数`pitch`指定的音高。
    volume String 否 在合成时，指定音频的音量，在0～9之间（只支持整型值），不传时默认为5
    优先级高于接口请求参数`volume`指定的音量。
    bgm String 否 为合成的语音添加指定的背景音乐。
    backgroundMusicVolume String 否 控制背景音乐的音量。
    [0,100]之间的整数。默认值为50。大于50表示增大音量。小于50表示减小音量。

    • bgm属性，添加背景音乐

      您可以根据需求，使用自定义的背景音。需要将背景音上传到标贝开放平台后台，在后台生成音频链接后，每次使用时在属性值里添加音频链接。长文本合成会分段合成，暂不支持添加长音频背景音乐。

      音频要求：

      • 采样率：16KHz
      • 声道：单声道
      • 格式：WAV

      • 合成时长超出背景音时长时，背景音将随合成音频循环播放。
      • 如果背景音不是WAV格式，可使用ffmpeg将其转为WAV格式：ffmpeg -i 输入音频 -acodec pcm_s16le -ac 1 -ar 16000 目标.wav。
      • 标签内的URL如果包含XML的特殊字符，需要做字符转义。

停顿时间<break>

  • 描述

    用于在文本中设置停顿时间，该标签是可选标签。

  • 语法

    # 空属性
<break/>
# 带time属性
<break time="string"/>

  • 属性

    属性名称 属性类型 属性值 是否必选 描述
    time String [number]s/[number]ms 否 以秒/毫秒为单位设置停顿的时长 （如“2s“、“50ms”）。
    [number]s：以秒为单位，[number]取值范围为[1, 15]的整数。
    [number]ms：以毫秒为单位，[number]取值范围为[50, 15000]的整数。
    strength String none
    x-weak
    weak
    medium
    strong
    x-strong
    		 否 none: 无停顿。常用于消除默认停顿的部分，对应xml标签<pause type=#0>
    x-weak: 无停顿。和none效果一致，对应xml标签<pause type=#1>
    weak: 短停顿，停顿时间比标准停顿更短，对应xml标签<pause type=#2>
    medium: 标准停顿，相当于标点符号的效果，对应xml标签 <pause type=#3>
    strong: 长静音，400ms <silence len=400>
    x-strong: 段落静音，500ms <silence len=500>

  • 标签关系

    <break>是空标签，不能包含任何标签。如果SSML结构中存在<s>标签，请把<break>写在<s>里面，表示对当前段落或句子设置停顿。 注：在使用该标签时，需要确保在标签前后不能只是空白或标点符号。

  • 示例

    <speak>
   请找一个舒适的地方坐下<break time="500ms"/>慢慢放松呼吸
</speak>

读音更改<phoneme>

  • 描述

    用于可以指定标签内汉字的拼音，该标签是可选标签。英文文本不支持该标签。

  • 语法

    <phoneme alphabet="string" ph="string">文本</phoneme>

  • 属性

    属性名称 属性类型 属性值 是否必选 描述
    alphabet String py 是 “py”表示拼音。
    ph String 标签内文本对应的拼音串 是 拼音用法的赋值规范：字与字的拼音用空格分隔，拼音的数目必须与字数相等。每个拼音由发音和音调组成，音调为1~5的数字编号，其中”5”表示轻声。

  • 标签关系

    <phoneme>标签仅包括文本。

  • 示例

    <speak>
    你这<phoneme alphabet="py" ph="zhao1">着</phoneme>真绝，让他干<phoneme alphabet="py" ph="zhao2 ji2">着急</phoneme>
</speak>

    测试音频（点击播放）

选择指定场景读法<say-as>

  • 描述

    用于指示出标签内文本的信息类型，进而按照该类型的默认发音方式发音。

  • 语法

    <say-as interpret-as="string">文本</say-as>

  • 属性

    属性名称 属性类型 属性值 是否必选 描述
    interpret-as String cardinal
    digits
    telephone
    name
    address
    id
    characters
    punctuation
    date
    time
    currency
    measure     		是 指示出标签内文本的信息类型：
    cardinal：数字读法
    digits：电报读法
    telephone：按电话号码常用方式发音
    name：按人名发音
    address：按地址发音
    id：适用于账户名、昵称等
    characters：将标签内的文本按字符一一读出
    punctuation：将标签内的文本按标点符号的方式读出来
    date：按日期发音
    time：按时间发音
    currency：按金额发音
    measure：按计量单位发音。

  • 标签关系

    <say-as>标签仅包括文本。
