标贝开放平台通用规则

本规则是服务协议的组成部分，用于明确开发者入驻、账户安全、接口调用、数据处理和应用运营要求。

规则效力

  • 本规则与服务协议具有同等效力。规则未约定的事项，适用服务协议及对应产品规则。
  • 平台可根据运营需要修改规则，并在公告区或相关页面公布；公布后按页面说明生效。
  • 开发者应同时遵守已签署的其他协议、产品说明、操作手册、隐私政策和服务等级协议。

入驻规范

  • 按照平台流程完成注册及必要的主体信息认证。
  • 提交真实、合法、有效的主体资料、联系人信息和应用信息，并在发生变化时及时更新。
  • 配合平台进行安全评估、风险核验和服务能力确认。
  • 应用名称、简介、内容和功能不得侵害他人权益，不得包含违法或误导性信息。

账户与安全规范

  • 账户、密码、client_secret、access_token 等凭证应妥善保管，不得明文公开或提交到公共代码仓库。
  • 发现凭证泄露、异常调用或其他安全问题时，应立即停止使用相关凭证并联系平台处理。
  • 不得冒用其他开发者身份、绕过权限、攻击服务、传播恶意代码或影响其他用户正常使用。
  • 接口调用应基于真实业务需求，遵守频率、并发、音频格式、文本长度和其他产品限制。

数据处理规范

  • 仅收集实现业务功能所必要的数据，并向用户说明收集目的、范围和使用方式。
  • 对数据采取访问控制、加密、脱敏、备份和日志审计等合理保护措施。
  • 不得将平台返回的数据用于未授权的交易、推广、画像、转售或其他超出约定的用途。
  • 发生数据泄露、丢失或异常访问时，应及时采取补救措施并按约定通知相关方。

应用运营规范

  • 开发者应独立负责应用的开发、运营、客服、内容审核和用户投诉处理。
  • 不得通过应用传输恶意文件、进行恶意广告、诱导分享、批量骚扰或其他破坏用户体验的行为。
  • 平台有权依据风险情况采取提醒、限流、暂停接口、冻结账户或终止服务等措施。
