标贝开放平台通用规则

概述

  • 1.1 为促进开放、透明、分享、公平的商业环境，保障标贝开放平台（以下简称“开放平台”或“平台”）客户的合法权益，维护开放平台正常经营秩序，制定本《平台通用规则》。《平台通用规则》作为《标贝开放平台服务协议》（以下简称“主协议”）的附件，与主协议具有同等法律效力。
  • 1.2 除主协议和本规则外，开发者应同时遵守与标贝开放平台运营者关联公司所签订的各项纸质及电子协议。
  • 1.3 本规则中的名词，除本规则另有定义外，与主协议中的术语含义相同。
  • 1.4 标贝开放平台有权在不单独通知开发者的情况下，随时对本规则内容进行修改，并通过“标贝开放平台/公告区”公告的方式予以公布。标贝开放平台制定、修改的规则一经公布即自动生效，成为本规则的一部分，除非规则另行规定生效时间。如开发者继续使用标贝开放平台服务的，则视为开发者接受并同意遵守修改后的规则条款。
  • 1.5 如本规则的展示位置发生变化的，标贝开放平台将通过公告的方式提前通知。

定义

  • 2.1 开发者：指经有效申请并经过标贝同意，在自行开发的应用中使用标贝开放平台所提供语音技术服务的具备完全民事行为能力的个人、法人或其他组织。开发者应经过企业或个人的实名认证，未认证通过的开发者不得在其开发的应用中使用在标贝开放平台上的语音技术服务。
  • 2.2 用户：是指所有直接或间接使用标贝开放平台上展示的各种应用和服务的用户。
  • 2.3 标贝开放平台：指由标贝所拥有、控制、经营的面向开发者提供智能语音产品服务的开放平台。
  • 2.4 应用：指由开发者自行开发的可向用户提供各种服务的应用程序，包括但不限于电子商务类服务、游戏类服务、工具类服务、文化娱乐类服务等现存的各种服务。
  • 2.5 产品服务：指标贝开放平台基于本协议提供的各项产品及其相关服务，也称“标贝开放平台产品服务”，具体信息请参见标贝官网及相关产品服务规则。
  • 2.6 产品服务规则：指标贝开放平台通过标贝科技官网及开放平台控制台或任何其他方式公布并可根据业务需要随时更新的，与标贝开放平台产品服务相关的任何文档、协议、规则、政策条款等，包括但不限于产品表述、产品定价、操作手册、隐私政策、服务等级协议（SLA）等。
  • 2.7 有效期：指订单中显示的您付费订购相关产品服务的期限。

平台规范

  • 3.1 入驻规范
    • 3.1.1 开发者应按遵循标贝开放平台设置的注册流程完成注册并进行实名认证。相关注册要求详见《标贝开放平台服务协议》，开发者在注册时应遵守国家法律法规，注册信息不得包含违法、涉嫌侵犯他人权利或干扰标贝开放平台秩序等相关内容。
    • 3.1.2 开发者应当提供真实、合法、有效的入驻材料及信息等。标贝开放平台可能定期或不定期地对开发者提供的该等资料和信息进行核查。若开发者提供的资料或信息不完整或不准确，则可能无法使用标贝开放平台产品服务或在使用标贝开放平台服务过程中受到对应限制。
    • 3.1.3 标贝开放平台有权根据实际情况对开发者进行评估，届时开发者应按平台要求提供如下信息安全相关材料，并接受评估。
      • 3.1.3.1 信息安全监控与审计方面的管理制度及技术措施；
      • 3.1.3.2 信息安全评估等持续改进机制。
      • 3.1.3.3 通过实施SDL等方式保障研发、服务过程的安全性；
      • 3.1.3.4 企业内部的信息安全标准、规范体系介绍；
      • 3.1.3.5 保障客户信息在产生、采集、存储、分发及销毁环节的技术手段措施，包括服务器的安全防护措施，防止被攻击导致用户的信息泄密或无法正常访问；
      • 3.1.3.6 出现风险时的应急响应和处理能力。
    • 3.1.4 开发者应严格按照法律法规使用标贝开放平台的服务，运营其在平台申请创建的应用，履行相关义务，并自行承担全部责任，包括但不限于：
      • 3.1.4.1 依照法律法规的规定，保留相应的访问、使用日志记录。
      • 3.1.4.2保证开发者的应用、提供给客户的相关服务及发布的相关信息、内容等，不违反法律法规等的规定，主协议、本规则或标贝开放平台发布的其他规则等，也不会侵犯任何人的合法权益。
      • 3.1.4.3保证应用中由客户使用产生的内容（包括但不限于留言、消息、评论、名称）不违反法律法规的规定以及公序良俗等。否则，开发者应及时采取删除、断开连接或其他有效措施。
  • 3.2 安全规范
    • 3.2.1 开通标贝开放平台服务的账户仅限于开发者自身使用，开发者不得将该账户以任何形式向第三方转让、出租、出借、泄露、披露等。开发者应妥善保管账户和密码等可识别开发者身份的信息，并对使用该账户和密码所进行的一切行为承担全部责任。开发者承诺在密码或账户等信息遭到未获授权的使用，或者发生其他安全问题时，将立即联系标贝开放平台运营人员协助处理。
    • 3.2.2 开发者应独立进行开发、运营、支持和维护应用，并同意独立承担所有风险和后果。标贝开放平台不对开发者发布在标贝开放平台上的任何不准确或不正确的内容或信息承担责任，无论上述不准确或不正确的内容或信息是由客户所造成的，还是由于应用所使用的或与应用相连接的任何设备或程序所造成的。
    • 3.2.3 开发者不得有如下行为：
      • 3.2.3.1 从标贝开放平台的任何方面篡改或部分删除任何标识、商标、版权或其他声明。
      • 3.2.3.2 分发、销售、转销、租赁、许可、再许可或通过其他方式将标贝开放平台或任何客户信息提供给第三方（包括以任何方式存储标贝开放平台或客户信息使第三方能够访问）。
      • 3.2.3.3 开发者应用中含有任何类型的恶意计算机程序、病毒，以任何方式干扰或企图干扰标贝开放平台、其他开发者应用或其任何部分或功能的正常运行。
      • 3.2.3.4 开发者应用里直接或间接与下述各项内容链接：（A）任何法律、法规、条例或规章所禁止的商品或服务；或（B）无权链接或包含的商品或服务。
      • 3.2.3.5 将通过标贝开放平台接口、公开渠道以及基于本规则项下合作获取的平台及其关联公司的相关数据（包括但不限于任何客户信息、客户交易信息、客户针对开发者产品的使用数据）用于主协议和本规则规定之外的目的。
      • 3.2.3.6 非法、或违反客户数据规范获取标贝开放平台客户信息用于交易或获取不当利益。
      • 3.2.3.7 为任何客户自动登录到标贝开放平台、客户端、接口提供代理身份验证凭据。
      • 3.2.3.8 提供“跟踪”功能，包括但不限于识别其他客户在开发者应用档案文件页上查看或操作。
      • 3.2.3.9 利用其他开发者的ID或相关权限获取、使用运营数据、客户数据。
      • 3.2.3.10 请求、收集、索取或以其他方式从任何客户那里获取对客户的账号（通行证）、用户名、密码或其他身份验证凭据的访问权。
    • 3.2.4 接口调用规范
      • 3.2.4.1 接口调用应当基于真实的业务需求。
      • 3.2.4.2 获取信息类接口仅在发生真实业务关系时进行调用，且仅能用于处理业务，不得用于其他用途。
    • 3.2.5 客户数据规范

      开发者的应用如涉及对于客户数据的收集、保存、使用等，开发者需要遵守以下规范：

      • 3.2.5.1 未经客户事先明确授权，开发者或其应用不得收集客户任何数据的，并且开发者仅可收集为应用运行及功能实现目的而必要的客户数据，同时应当告知客户相关数据收集的目的、范围及使用方式等。
      • 3.2.5.2 开发者收集客户数据后，必须采取合理、安全、有效的保护措施，防止客户数据被盗、泄漏等。
      • 3.2.5.3 开发者应向客户在应用的明显位置向客户公示隐私保护政策。
      • 3.2.5.4 开发者应当向客户提供修改、删除数据的方式，确保客户通过该方式自行操作完成与客户有关的数据的删除。
      • 3.2.5.5 一旦发生客户数据被盗、被泄露等情形，不得隐瞒，必须立即通知客户以及标贝开放平台，并及时采取相应的法律措施保护客户利益，以及防止损害进一步扩大。
      • 3.2.5.6 开发者在向商户展示用户信息时，需要将用户敏感信息（例如身份证号、手机号等）进行脱敏展示，避免商户滥用或泄露用户的敏感数据。
      • 3.2.5.7 应用需采用技术措施防止明文展示的敏感信息被爬取。
  • 3.3 使用规范
    • 3.3.1 开发者通过标贝开放平台提供的产品技术服务所开发的应用需遵守以下：
      • 3.3.1.1 应用不得进行传输病毒文件、代码程序导致破坏或扰乱应用正常使用的行为。
      • 3.3.1.2 应用不得进行恶意推广广告的行为。
      • 3.3.1.3 应用不得进行泄露系统的高危端口，或者对系统的能力进行二次分发的行为。
      • 3.3.1.4 应用使用标贝提供的相关能力时，应当标注相关能力来自标贝。
      • 3.3.1.5 应用不得进行非法窃取或上传用户隐私信息。
      • 3.3.1.6 应用不得存在强制推荐下载其他程序才能正常使用的行为。
    • 3.3.2 隐私保护
      • 3.3.2.1 应用在需要收集用户数据时，应事先获得用户的授权同意，并应明确地告知用户其相关数据收集的目的、范围及使用方式。
      • 3.3.2.2 获取的用户数据或其他标贝开放平台数据用于交易、披露、提供给第三方或其他本协议约定之外的用途的将收到相关处理。
      • 3.3.2.3 用户将相关标贝能力的日志信息非法导出并共享给其他第三方的将收到相关处理。
    • 3.3.3 应用经营
      • 3.3.3.1 应用通过创建后超过3个月未进入或应用60天内无服务调用的，可能将被禁用。
      • 3.3.3.2 恶意隐瞒标贝开放平台漏洞进行利用，从而非法获利的将收到相关处理。
      • 3.3.3.3 应用相关企业或产品不得含有负面报道，不得对标贝开放平台关联公司声誉造成影响。
    • 3.3.4 其他情况
      • 3.3.4.1 应用名称不得超过12个汉字或24个字符，不得含有特殊符号或空格。
      • 3.3.4.2 应用功能描述中不得包含特殊符号（空格除外）。
      • 3.3.4.3 应用名称、应用功能涉及第三方企业或产品的信息或其他内容时，需要有其相关方面的授权。
      • 3.3.4.4 应用名称、分类、应用功能描述与实际应用应有直接关联，未明确说明应用使用场景与功能的将被进行处理。
      • 3.3.4.5 用户为规避应用付费而重复申请多个应用调用平台语音试用用量的将被进行处理。
      • 3.3.4.6 反政治、反科学
        • 1）应用不得含有煽动性的涉政言论、散布谣言，或其他法律明令禁止的内容。
        • 2）应用不得含有扰乱社会秩序，破坏社会稳定信息。
        • 3）应用不得含有反政府、反社会或不符合主流社会主义价值观的内容。
      • 3.3.4.7 色情赌博等信息
        • 1）应用不得含有涉嫌宣扬传播淫秽、色情内容信息，包括暴露图片、挑逗内容。
        • 2）应用内容不得含有非法色情交易的信息。
        • 3）应用不得通过虚拟货币兑换实物（现金或奖品）的方式，吸引用户进行赌博、竞猜等。
        • 4）应用不得含有色情内容（对性器官或性行为的明确描述或展示）。
        • 5）应用不得以虚拟货币或真实货币直接进行押输赢、竞猜、参与赌博等。
        • 6）应用不得以或包含宣扬赌博的名称作为应用的名称。
        • 7）应用不得含有其他被认定为宣扬赌博内容。
        • 8）应用内容不得包含侮辱或者诽谤他人，侵害他人合法权益信息。
      • 3.3.4.8 特殊类别应用

        应用提供的相关服务属于国家管制、专营、专控等特殊领域服务的，如理财、金融、支付、新闻、媒体、医药等 ，开发者需通过相关的资质认证和行政审批，无法提供相关资料的将被进行处理。

违规行为

  • 4.1 开发者出现任意一种违反主协议或本规则的行为（“违规行为”），或为违规行为提供便利（包括但不限于为客户行为提供便利），开发平台有权进行独立判断并针对开发者或者开发者的应用采取违规处理措施。
  • 4.2 开发者不得出现任何违反法律法规的行为，包括但不限于：
    • 4.2.1 实施涉嫌博彩、赌博、“私服”、“外挂”等非法互联网活动或其他欺诈、误导行为；
    • 4.2.2 实施侵害标贝开放平台或第三方肖像权、名誉权、隐私权、知识产权等任何合法权益的行为；
    • 4.2.3 以过度负荷或其他任何方式导致网络中断，或实施未经授权的截取、盗用、干扰或监测等违法行为；
    • 4.2.4 发布违法、违规、虚假信息或未经接收方许可进行商业短信、邮件发送或其他骚扰式营销行为；
    • 4.2.5 利用任何技术手段或以任何方式对产品服务和相关数据进行破译、破解等行为，刺探或试图获取标贝开放平台用户个人信息或相关用户信息；
    • 4.2.6 利用标贝开放平台提供的互联网资源经营任何您不具备资质的互联网业务；
    • 4.2.7 实施任何破坏或试图破坏网络安全的行为，包括但不限于以病毒、木马、恶意代码、钓鱼等方式，对网站、服务器进行恶意扫描、非法侵入系统、非法获取数据等；
    • 4.2.8 实施任何改变或试图改变产品服务提供的系统配置或破坏系统安全的行为；
    • 4.2.9 利用技术或其他手段破坏、扰乱标贝开放平台的运营或影响他人对产品或服务的使用；
    • 4.2.10 其它可能给标贝开放平台造成不良影响或损失的行为。
    • 4.2.11 开发者不得出现任何弄虚作假的行为，包括但不限于：
      • 4.2.11.1 开发者在标贝开放平台注册过程中所提交的所有资质、信息和材料发生变更的，未及时向标贝开放平台提交变更后资质、信息和材料的。
      • 4.2.11.2 向标贝开放平台提供虚假、伪造、篡改的材料或信息。
      • 4.2.11.3 其他弄虚作假的行为或情形。
    • 4.2.12 开发者不得出现任何损害标贝开放平台及关联公司名誉的行为，包括但不限于：
      • 4.2.12.1 散布关于标贝开放平台或其关联公司的不实、片面、引人误解的言论。
      • 4.2.12.2 公开发表关于标贝开放平台或其关联公司的负面言论。
    • 4.2.13 开发者不得出现任何违反保密义务（包括但不限于法律规定的、或标贝开放平台制定的各类协议、规则规定的开发者应当承担的保密义务）的行为，包括但不限于：
      • 4.2.13.1 向第三方披露标贝开放平台提供的接口相关的任何资料和信息，或者是披露其他开发者通过标贝开放平台提供的接口所获取到的任何资料和信息。
      • 4.2.13.2 经由分发、销售、转销、租赁、许可、再许可或通过其他方式而致使标贝开放平台提供的接口信息泄露或开发者通过标贝开放平台提供的接口所获取到的信息泄露（包括但不限于开发者主动向第三方透露、因开发者过失将信息透露给第三方或被第三方盗用）的行为。
      • 4.2.13.3 其他违反保密义务的行为。
    • 4.2.14 开发者不得使用其他开发者的账户或使用其他开发者的权限，盗取他人信息；或通过不正当手段获取他人资料。
    • 4.2.15 开发者不得出现任何扰乱或影响标贝开放平台运营的行为，包括但不限于：
      • 4.2.15.1 开发者刻意规避标贝开放平台的各类规则或市场管控措施。
      • 4.2.15.2 在标贝开放平台开发或发布的应用含有恶意计算机程序、病毒或在标贝开放平台恶意植入计算机程序、病毒或者开发的应用中存在安全漏洞或风险。
      • 4.2.15.3 开发者干扰或企图干扰标贝开放平台、其他开发者应用或其任何部分或功能的正常运行。
      • 4.2.15.4 开发者使用其他开发者的AppID和私钥，或将自身的AppID和私钥提供给第三方。
      • 4.2.15.5 篡改或从标贝开放平台、开发者服务的任何方面或部分删除任何标识、商标、版权或其他声明。
      • 4.2.15.6 避开或修改标贝开放平台数据统计工具。
      • 4.2.15.7 未经标贝开放平台授权，利用标贝开放平台提供的接口集成的产品对标贝开放平台及其关联公司的业务存在冲突、竞争或名誉造成伤害。
