一句话识别 Android SDK

一句话识别 Android SDK 适用于 60 秒以内短语音识别，支持 SDK 调用麦克风录音识别，也支持接收音频字节流并上传识别。

下载安装

SDK 及示例 Demo 下载地址：https://github.com/data-baker/BakerAndroidSdks

项目中使用一句话识别能力时，将以下 AAR 包复制到主 Module 的 libs 目录：

basecomponent-release.aar
bakerasr-release.aar
bakerhttp-release.aar

Android Studio 集成

dependencies {
  implementation fileTree(dir: 'libs', include: ['*.aar'])
  implementation 'com.squareup.okhttp3:okhttp:4.2.2'
  implementation 'com.google.code.gson:gson:2.8.6'
}

在 AndroidManifest.xml 中声明网络和录音相关权限；Android 6.0 及以上还需要动态申请 READ_PHONE_STATE 与 RECORD_AUDIO。

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.READ_PHONE_STATE" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />

如需允许明文网络访问，在 application 节点增加：

android:usesCleartextTraffic="true"

SDK 关键类

类名说明
BakerRecognizer一句话识别业务处理类，全局只需一个实例。
BakerRecognizerCallback实时识别结果、状态和错误信息回调类。

初始化 SDK

调用公共识别服务时，传入授权邮件中的 clientId 与 clientSecret：

BakerRecognizer bakerRecognizer = new BakerRecognizer();
bakerRecognizer.initSdk(context, clientId, clientSecret, bakerRecognizerCallback);

私有化部署时，先初始化回调，再设置识别服务器地址：

bakerRecognizer.initSdk(context, bakerRecognizerCallback);
bakerRecognizer.setUrl("ws://xxxx");

识别场景

麦克风录音识别

  1. 初始化 BakerRecognizer 并配置参数。
  2. 调用 startAsr() 开始录音识别。
  3. 在 BakerRecognizerCallback 中接收状态、识别结果或错误信息。
  4. 开启 VAD 时可由服务端自动结束；未开启时调用 stopAsr() 主动结束。

音频字节流识别

  1. 调用 start() 通知 SDK 准备识别。
  2. 多次调用 send(byte[] data) 输入待识别音频数据。除最后一片外，单次建议固定为 5120 字节。
  3. 最后一片可以小于 5120 字节，也可以发送空包。
  4. 调用 end() 结束识别并释放本次任务。

参数与方法

方法是否必填说明
initSdk是初始化 SDK，设置授权信息和回调。
setUrl否设置识别服务器地址，仅私有化部署需要。
setSampleRate否设置采样率，支持 8000、16000，默认 16000。
setAudioFormat否输入字节流识别时设置音频编码格式，支持 pcm、wav。
setDomain否设置模型名称，默认 common。
setAddPct否设置是否返回标点，默认 true。
setHotwordid否配置热词组 ID。
setDiylmid否配置 ASR 个性化模型 ID。
setEnable_vad否设置是否开启静音检测，默认关闭。
setMax_begin_silence否开启 VAD 后有效，允许的最大开始静音时长，单位毫秒，范围 200-60000。
setMax_end_silence否开启 VAD 后有效，允许的最大结束静音时长，单位毫秒，范围 200-5000。
startAsr场景相关启动麦克风录音识别。
stopAsr场景相关结束麦克风录音识别。
start场景相关启动字节流识别任务。
send(byte[] data)场景相关发送音频字节流分片。
end场景相关结束字节流识别任务。

BakerRecognizerCallback 回调

方法说明
onReadyOfSpeech授权通过并与服务器连接成功，识别准备就绪。
onBeginOfSpeech检测到开始说话。
onEndOfSpeech检测到说话结束。
onVolumeChanged(int volume)音量变化回调。
onResult(BakerResponse response)识别结果回调，可能多次返回。可读取 nbest、uncertain、isLast 等信息。
onError识别出错回调，任务会中断。

响应结果结构

字段类型说明
res_idxint数据块序列号，从 1 递增。
nbestarray识别候选结果。
end_flagint是否最后一个数据块，0 否，1 是。
textstring语音识别结果，失败时为空。
confidenceint整句置信度，范围 0-100。
speedint语速，范围 0-2000。
speed_labelstring语速标签：FAST、MEDIUM、SLOW。
volumeint音量，范围 0-100。
volume_labelstring音量标签：SILENT、XSOFT、SOFT、MEDIUM、LOUD、XLOUD。
wordsarray词级别识别结果，包含 confidence、sos、eos、word。
