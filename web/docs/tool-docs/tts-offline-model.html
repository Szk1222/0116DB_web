模型文件说明

作用

开放平台新增离在线融合语音合成技术，当用户于（应用 / 离线合成）服务下【发音人管理】获取新的发音人，则需要在原有SDK的基础上添加新音色的模型资源文件，以便后续合成更丰富的声音。

模型资源文件包：由 音色资源文件+公共参数文件两部分组成。

音色资源文件：内包含已获取的不同音色的资源文件。

示例步骤

1、获取了新的发音人（贝茹 3.0）

2、点击下载新获取音色的模型资源文件（注：获取3.0的音色则对应下载3.0模型文件）

3、勾选您新获取的发音人（贝茹 3.0），点击下载开始下载

4、下载等待（注：单个文件下载时长在1分钟内，如有多个音色请等待下载，勿刷新页面）

5、 解压下载的模型资源文件包，并设置到您已有的SDK （相关设置请参见 Android iOS开发文档）
