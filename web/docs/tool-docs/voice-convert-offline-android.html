离线声音转换 Android SDK

离线声音转换 Android SDK 无需持续联网即可在设备端完成声音转换。首次授权激活需要联网，后续转换可在无网络环境中进行。

下载安装

SDK 与示例 Demo 地址：https://github.com/data-baker/VoiceConvertOffLine

将 voiceconvertoffline-release.aar 放入业务 Module 的 libs 目录，并在 Module 的 Gradle 文件中加入：

dependencies {
  implementation fileTree(dir: 'libs', include: ['*.aar'])
  implementation 'com.squareup.okhttp3:okhttp:4.2.2'
  implementation 'com.google.code.gson:gson:2.8.6'
}

如果项目已经引入 OkHttp 或 Gson，请确认版本兼容，避免重复引入。

权限与混淆

在 AndroidManifest.xml 中加入以下权限。Android 6.0 及以上还需要动态申请录音和存储权限。

<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />

使用 R8 或 ProGuard 时加入：

-keep class com.baker.voiceconvert.offline.bean.** { *; }
-keep public class com.baker.voiceconvert.offline.VoiceConvertOffLineManager { *; }
-keep public class com.baker.jni.voice.convert.VoiceConvertEngine { *; }
-keep public class com.baker.voiceconvert.offline.callback.OffLineConvertCallBack { *; }
-keep public class com.baker.voiceconvert.offline.util.WriteLog { *; }
-keep public class com.baker.voiceconvert.offline.callback.ConvertInnerCallBack { *; }
-keep public class com.baker.voiceconvert.offline.util.ThreadPoolUtil { *; }
-keep public class com.baker.voiceconvert.offline.util.HLogger { *; }

关键类

类名说明
VoiceConvertOffLineManager声音转换业务处理类，应用内保留一个实例即可。
OffLineConvertCallBack返回准备状态、转换数据、播放状态和错误信息。回调方法运行在子线程。

初始化

VoiceConvertOffLineManager manager = new VoiceConvertOffLineManager();
manager.initVoiceConvertSDK(context, clientId, secret, callback);
manager.setSpeakerId("Vc_luoli");

initVoiceConvertSDK 会执行授权请求。建议尽早调用，以便预留授权时间。设备首次激活需要联网，激活后可离线使用。

转换场景

麦克风录音转换

  1. 取得录音和存储权限。
  2. 调用 startRecordAndConvert() 开启录音转换。
  3. 收到 onReadyForConvert() 后开始处理返回数据。
  4. 通过 onResult(byte[] audioData, int endFlag) 实时获取转换结果，endFlag == 1 表示结束。
  5. 调用 stopRecord() 结束录音，完成后触发 onConvertCompleted()。

PCM 文件转换

  1. 调用 startConvertByPCM() 初始化文件转换。
  2. 收到 onReadyForConvert() 后调用 convert(path)。
  3. 在回调中接收转换数据，完成后调用 play() 播放，或自行处理音频数据。

PCM 字节流转换

  1. 调用 startConvertByPCM() 并等待 onReadyForConvert()。
  2. 多次调用 sendData(byte[] audioData, int index) 发送 PCM 数据，序号从 0 开始递增。
  3. 最后一包将序号乘以 -1；也可以发送空包并使用负数序号结束输入。
  4. 通过 onResult 接收转换数据，完成后触发 onConvertCompleted()。

三种方式都会实时返回结果，并将原始录音和转换结果缓存为 PCM 文件。后一次任务会覆盖前一次任务生成的文件。

方法说明

方法作用
initVoiceConvertSDK(context, clientId, secret, callback)初始化并授权 SDK。
startRecordAndConvert()开启麦克风录音转换。
stopRecord()结束录音转换。
startConvertByPCM()开启 PCM 文件或字节流转换。
convert(String path)转换指定 PCM 文件。
sendData(byte[] audioData, int index)发送 PCM 字节流，负数序号表示最后一包。
setSpeakerId(String speakerId)设置目标音色名称，默认值为 Vc_luoli。
setVadEnable()设置是否启用 VAD。
play() / pause() / stopPlay()控制 SDK 内置播放器。
getOriginRecordFile()获取 SDK 录制的原始文件路径。
getConvertResultFile()获取转换结果文件路径。
release()释放 SDK 资源。

回调说明

回调说明
onReadyForConvert()授权通过并准备完成，三种转换方式都会触发。
onResult(byte[] audioData, int endFlag)实时返回转换后的音频数据，endFlag == 1 表示转换结束。
onConvertCompleted()本次转换完成。
volumeChange(int volume)返回 SDK 录音过程中的音量分贝值，约每 100ms 回调一次。
onPlaying() / onPaused() / onPlayCompleted() / onStopped()播放器状态回调。
onError(String errorCode, String errorMessage)返回错误码和错误信息。
