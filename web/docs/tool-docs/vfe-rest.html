声音理解 RESTful API

声音理解接口根据音频数据分析说话人的性别、年龄和音频类别，返回结构化结果。

音频要求

  • 格式：PCM。
  • 采样率：16000Hz。
  • 位深：16bit。
  • 声道：单声道。
  • 时长：最短 1 秒，最长 30 秒。
  • 音频需要先进行 Base64 编码。

调用流程

  1. 在开放平台创建账号和应用，获取 client_id 与 client_secret。
  2. 调用访问令牌接口获取 access_token。
  3. 向声音理解接口提交 JSON 请求。

请求说明

接口类型：REST API。

服务接口：https://openapi.data-baker.com/vcf/voiceClassification

请求方法：POST。请求头：Content-Type: application/json。

请求参数

参数类型必填说明
access_tokenString是访问令牌。
formatString是固定为 pcm。
audioString是Base64 编码后的音频数据，需满足音频要求。
request_typeString是gender 性别，age 年龄，category 类别，all 全部返回。
 
{
  "access_token": "your_access_token",
  "format": "pcm",
  "audio": "BASE64_AUDIO",
  "request_type": "all"
}

返回结果

返回数据为 JSON 格式，err_msg 为 SUCCESS 表示调用成功。

{
  "err_msg": "SUCCESS",
  "log_id": "1637549378324843",
  "err_no": 90000,
  "result": {
    "age": "middle",
    "category": "speech",
    "gender": "male"
  }
}
字段类型说明
genderStringmale 或 female。
ageStringchild、middle 或 old。
categoryStringspeech 或 noise。

错误码

错误码说明
90000成功。
10001 - 10003请求参数、请求体或请求头错误。
20001 - 20003数据库、资源或缓存服务错误。
30001 - 30005音频过长、过短、数据错误、调用次数或并发超限。
30006请求类型错误。
40001引擎内部错误。
50001 - 50002访问令牌校验失败或无效。
