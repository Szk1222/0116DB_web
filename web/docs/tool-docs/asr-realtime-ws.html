实时长语音识别 Websocket API

实时长语音识别 Websocket API 用于对长时间持续输入的语音流进行实时识别，适用于视频直播字幕、会议记录、实时演讲字幕等场景。

功能介绍

  • 支持语言：中文普通话、英文、粤语、维语。
  • 支持添加标点，支持将中文数字转换为阿拉伯数字输出。
  • 支持连续返回中间识别结果，实现连续上屏效果。
  • 单次识别时长不超过 3 小时。

音频要求

项目要求
音频格式wav、pcm（Linear PCM）
采样率8000Hz、16000Hz
位深16bits
声道单声道
时长不超过 3 小时

使用方法

  1. 创建账号和应用，在开放平台应用服务中获取 client_id 与 client_secret。
  2. 调用授权服务获取 access_token。
  3. 建立 WebSocket 连接。
  4. 实时发送需要识别的音频分片。
  5. 接收中间识别结果和最终识别结果。
  6. 收到最终包后关闭连接。
  • WebSocket 握手会受网络环境影响产生延迟，接入方需要结合实际测试处理。
  • 结束识别时不要立即关闭麦克风，可延迟数百毫秒保留部分环境静音，有助于 VAD 快速结束。
  • 最后一个数据包发送后，需要等待最终识别结果返回；响应参数 end_flag=1 表示最后一个包。

请求消息

请求消息和响应消息均序列化为 JSON 格式。请求顶层包含 access_token、version 和 asr_params。

参数名称类型是否必填说明
access_tokenstring是通过 client_id、client_secret 调用授权服务获得。
versionstring是版本信息，当前为 1.0。
asr_paramsobject是ASR 识别参数对象。

asr_params 参数

流式接口需要将音频分包发送。除最后一包外，每包长度固定为 5120 字节；最后一包不足 5120 字节时，发送剩余全部数据。每包音频需要进行 Base64 编码。

参数名称类型是否必填说明
audio_datastring是Base64 编码后的音频分片。
audio_formatstring是音频编码格式，支持 pcm、wav。
sample_rateint是音频采样率，支持 8000、16000。
req_idxint是音频序号索引，步长为 1 递增。0 为起始帧，正数为中间帧，负数为结束帧。
domainstring否模型名称，默认 common。
add_pctboolean否是否添加标点，true 添加，false 不添加。
hotwordidstring否配置的热词组 ID。
diylmidstring否ASR 个性化模型 ID。
enable_itnboolean否是否将中文数字转换为阿拉伯数字。

请求示例

{
  "access_token": "ACCESS_TOKEN",
  "version": "1.0",
  "asr_params": {
    "audio_format": "pcm",
    "sample_rate": 16000,
    "req_idx": 0,
    "audio_data": "BASE64_AUDIO_CHUNK",
    "add_pct": true,
    "enable_itn": true
  }
}

示例代码参考：real_time_audio_recognition

响应结果参数

字段类型说明
codeint结果码，9000 表示包含有效识别数据。
messagestring错误描述或结果描述。
trace_idstring任务 ID，用于定位错误和日志。
asr_textstring识别结果文本。
sentence_idint句子 ID，从 1 递增。
sentence_endboolean当前句子是否结束。true 表示当前句最终结果。
end_flagint是否最后一个数据块，0 否，1 是。
sosfloat句子在音频中的开始时间点，单位秒。
eosfloat句子在音频中的结束时间点，单位秒。
confidenceint整句置信度，范围 0-100。
speedint语速，范围 0-2000。
speed_labelstring语速标签：FAST、MEDIUM、SLOW。
volumeint音量，范围 0-100。
volume_labelstring音量标签：SILENT、XSOFT、SOFT、MEDIUM、LOUD、XLOUD。
wordsarray词级别识别结果，包含 confidence、sos、eos、word。

错误码

错误码含义处理建议
30001HTTP 请求参数错误检查请求参数。
30002服务内部错误保留 TraceID 并排查。
30005语音质量问题检查音频质量。
30006输入语音过长控制单次识别时长。
40002JSON 字段不全检查必填字段。
40006idx 超时相邻分片间隔超过超时时间，默认 60 秒。
40007idx 顺序错误检查音频分片序号。
40008Token 校验失败重新获取或检查 access_token。
40010Token 已过期重新获取 Token。
40013音频包长度错误检查音频分片长度。
40016错误的音频格式检查 audio_format。
40017错误的采样率检查 sample_rate。
50001处理超时稍后重试或缩短音频。
50003服务端繁忙稍后重试。
