离线声音转换 iOS SDK

离线声音转换 iOS SDK 支持在设备端完成麦克风录音、PCM 文件和 PCM 字节流转换。首次授权激活需要联网，后续转换可在无网络环境中进行。

下载安装与兼容性

SDK 与示例 Demo 地址：https://github.com/data-baker/BakerIosSdks

  • 系统版本：iOS 9.0 及以上。
  • CPU 架构：arm64、arm64e、armv7、armv7s。
  • 在 Info.plist 中加入 Privacy - Microphone Usage Description 麦克风权限说明。

关键类

类名说明
DBOfflineConvertVoiceClient离线声音转换业务处理类，应用内使用一个共享实例。
DBOfflineVoiceConvertDelegate返回准备状态、转换数据、播放状态和错误信息，回调在子线程执行。

初始化

DBOfflineConvertVoiceClient *convertClient =
    [DBOfflineConvertVoiceClient shareInstance];

[convertClient setupVoiceConvertSDKClientId:clientId
                               clientSecret:clientSecret
                              messageHander:^(NSInteger ret, NSString *message) {
  if (ret == 0) {
    NSLog(@"授权成功");
  } else {
    NSLog(@"授权失败 code:%@ message:%@", @(ret), message);
  }
}];

初始化会执行授权请求，建议在业务开始前尽早调用。设备首次激活需要联网，激活完成后不需要持续联网。

转换场景

麦克风录音转换

  1. 取得录音权限。
  2. 调用 startAndRecord 开启 SDK 录音。
  3. 在 onReadyForConvert 后通过 onResultData:data endflag: 接收实时转换数据。
  4. 调用 stopRecord 结束录音，完成后触发 onConvertComplete。
  5. 需要播放时调用 play，也可以自行处理回调中的音频数据。

PCM 文件转换

  1. 调用 startFileConvertPCMPath: 开启文件转换。
  2. 收到 onReadyForConvert 后，通过回调接收转换数据。
  3. 转换完成后触发 onConvertComplete，需要播放时调用 play。

PCM 字节流转换

  1. 调用 startConvertByPCM 并等待 onReadyForConvert。
  2. 多次调用 sendData:index: 发送音频数据，序号从 0 开始递增。
  3. 最后一包将序号乘以 -1，转换结果通过 onResultData:data endflag: 实时返回。

输入数据使用 PCM 格式时，应使用 16KHz、单声道、16bit 参数。每次转换的原始录音和结果文件会覆盖上一次任务生成的对应文件。

方法说明

方法作用
setupVoiceConvertSDKClientId:clientSecret:messageHander:初始化并授权 SDK。
startAndRecord开启麦克风录音转换。
stopRecord结束录音转换。
startFileConvertPCMPath:使用指定 PCM 文件进行转换。
startConvertByPCM开启 PCM 字节流转换。
sendData:index:发送 PCM 字节流，负数序号表示最后一包。
setupVoiceName:设置目标音色名称，默认值为 Vc_luoli。
play / pause / stopPlay控制 SDK 内置播放器。
getOriginRecordFile获取原始录音文件路径。
getConvertResultFile获取转换结果文件路径。

回调说明

回调说明
onReadyForConvert授权通过并准备完成，三种转换方式都会触发。
onResultData:data endflag:实时返回转换后的音频数据，endFlag == YES 表示转换结束。
onConvertComplete本次转换完成。
dbValues:返回 SDK 录音过程中的音量分贝值。
onPlaying / onPaused / onPlayCompleted / onStopped播放器状态回调。
onError:msg:返回错误码和错误信息。

错误码说明

22180006SDK 播放器错误。
