录音文件识别 Restful API

录音文件识别用于对已经录制完成的音频文件进行文字转写。接口采用异步调用方式，提交音频文件或可下载的文件 URL 后，系统创建识别任务，识别完成后可通过主动轮询或回调通知获取结果。

功能介绍

  • 支持通过请求体直接上传音频二进制数据。
  • 支持提交外网可访问的 file_url，服务端从指定 URL 下载音频文件。
  • 支持主动轮询查询任务结果，也支持在创建任务时传入 callback_url 接收回调通知。
  • 直接上传音频数据时，单次文件最大 64MB；通过音频 URL 提交时，文件最大 512MB。
  • 识别结果返回耗时受音频时长和排队任务量影响；高峰期请耐心等待。

音频要求

项目要求
单声道格式wav、pcm、mp3、ogg、flac
双声道格式wav、mp3、ogg、flac
采样率8000Hz、16000Hz。音频采样率高于 16000Hz 时，会按参数指定采样率降采样后识别。
位深16bits

使用方法

  1. 创建账号和应用，在开放平台应用服务中获取 client_id 与 client_secret。
  2. 调用授权服务获取 access_token。
  3. 调用新建任务接口，上传音频数据或传入 file_url，获取 taskid。
  4. 如果未设置 callback_url，使用 taskid 主动轮询查询识别结果。
  5. 如果设置了 callback_url，识别结束后服务端会向回调地址发送结果；长时间未收到回调时仍可使用 taskid 查询。

请求体

未指定 file_url 时，请将二进制音频数据放到 HTTP 请求体中；指定 file_url 时，服务端将忽略 HTTP 请求体。

新建任务示例

import requests

url = "https://openapi.data-baker.com/asr/starttask?"
headers = {
    "access_token": "ACCESS_TOKEN",
    "audio_format": "wav",
    "sample_rate": "16000",
    "channel": "1",
    "domain": "common"
}

with open("test.wav", "rb") as f:
    response = requests.post(url, headers=headers, data=f)

task_id = response.json().get("taskid")
print(task_id)

字段类型说明

codeint请求结果码，成功为 20000。

taskidstring识别任务 ID，后续查询识别结果时使用。

查询识别结果

主动轮询时，调用查询结果接口，并在 Header 中传入 access_token 与 taskid。

import time
import requests

url = "https://openapi.data-baker.com/asr/taskresult?"
headers = {
    "access_token": "ACCESS_TOKEN",
    "taskid": "TASK_ID"
}

while True:
    result = requests.post(url, headers=headers).json()
    if result.get("code") in (20000, 20001, 20005):
        if result.get("text"):
            print(result["text"].get("left_result"))
            break
        time.sleep(2)
    else:
        raise RuntimeError(result)

查询结果或回调通知均以 JSON 返回。任务失败时 text 为空。

回调通知

创建任务时传入 callback_url 后，识别完成会将识别结果发送到该地址。若长时间未收到回调，仍可根据 taskid 调用查询接口。

from flask import Flask, request
import json

app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def get_text():
    payload = json.loads(request.get_data())
    text = payload["text"]["left_result"]
    with open("result.txt", "w", encoding="utf-8") as f:
        f.write(text)
    return "finished"

错误码

错误码含义处理建议
20000请求成功按响应内容解析。
20001任务正在处理等待一段时间后继续查询。
20002taskid 无效使用新建识别任务返回的 taskid。
20005任务在队列中等待调度执行等待前序任务结束后自动处理。
20006音频分割后部分识别失败重新发送识别请求或联系技术人员。
20007音频分割后全部识别失败检查音频质量和格式后重试。
30001HTTP 请求参数错误检查请求参数。
30002服务内部错误保留 TraceID 并排查。
30003识别结果解析出错保留响应内容并排查。
30005语音质量问题检查音频清晰度、噪声和格式。
30006输入语音过长控制音频时长或拆分文件。
30015单个语音分片过长检查上传文件大小。
30016回调 URL 失败检查回调地址可访问性和服务状态。
50002内部 RPC 调用失败稍后重试或联系技术人员。
50009其他内部错误保留 TraceID 并排查。
