一句话识别 Websocket API

一句话识别 Websocket API 用于识别不超过 60 秒的短语音。相比 RESTful API，WebSocket 支持持续返回中间识别结果，可用于连续上屏、实时交互等场景。

功能介绍

  • 支持语言：中文普通话、中英自由说、英文、粤语、维语。
  • 支持添加标点，支持将中文数字转换为阿拉伯数字输出。
  • 支持连续返回中间识别结果，实现连续上屏效果。
  • 时长限制：60 秒以内。
  • 支持音频格式：wav、pcm；采样率：8000Hz、16000Hz；位深：16bits；声道：单声道。

使用方法

  1. 创建账号和应用，在开放平台应用服务中获取 client_id 与 client_secret。
  2. 调用授权服务获取 access_token。
  3. 建立 WebSocket 连接。
  4. 实时发送需要识别的音频分包。
  5. 接收返回结果，读取中间结果和最终结果。
  6. 收到最终包后关闭连接。
  • 建立 WebSocket 会话会受网络环境影响产生延迟，接入侧需要按实际测试结果处理。
  • 结束识别时不要立刻关闭麦克风，可延迟数百毫秒保留部分环境静音，有助于 VAD 快速结束。
  • 最后一个数据包发送后，应等待最终识别结果返回；响应参数 end_flag=1 表示最后一个包。

请求消息

请求消息和响应消息均序列化为 JSON 格式。请求顶层包含 access_token、version 和 asr_params。

参数名称类型是否必填说明
access_tokenstring是通过授权服务获得的访问令牌。
versionstring是版本信息，旧站文档标注当前为 1.0。
asr_paramsobject是ASR 识别参数对象，其中 audio_data 为必需字段，且需使用 Base64 编码。

asr_params 参数

流式接口需要将音频分包发送：除最后一包外，每包长度固定为 5120 字节；最后一包不足 5120 字节时发送剩余全部数据。每包音频需进行 Base64 编码。

参数名称类型是否必填说明
audio_datastring是Base64 编码后的音频分包。
audio_formatstring是音频编码格式，支持 pcm、wav。
sample_rateint是音频采样率，支持 8000、16000。
req_idxint是音频序号索引，步长为 1 递增；0 为起始音频帧，正数为中间音频帧，负数为结束音频帧。
domainstring否模型名称。16k 支持 common、cn-en-mixed、english、cantonese、uighur；8k 支持 kefu。
add_pctboolean否是否添加标点：true 添加，false 不添加。
hotwordidstring否配置的热词组 ID。
diylmidstring否ASR 个性化模型 ID。
enable_itnboolean否中文数字转换为阿拉伯数字，仅支持 3 位及以上数字串。
enable_vadboolean否是否开启静音检测：false 关闭，true 开启。
max_begin_silenceint否enable_vad=true 时有效，允许的最大开始静音时长，单位毫秒，范围 200-60000。
max_end_silenceint否enable_vad=true 时有效，允许的最大结束静音时长，单位毫秒，范围 200-5000。

请求示例

{
  "access_token": "ACCESS_TOKEN",
  "version": "1.0",
  "asr_params": {
    "audio_format": "wav",
    "sample_rate": 16000,
    "req_idx": 0,
    "audio_data": "BASE64_AUDIO_CHUNK",
    "add_pct": true,
    "enable_itn": true
  }
}

响应结果参数

字段名类型描述
codeint错误码，4xxxx 表示客户端参数错误，5xxxx 表示服务端内部错误。
messagestring错误描述或成功提示。
trace_idstring任务 ID，用于定位错误和跟踪日志。
dataobject识别结果数据。

data 内部结构

字段名类型描述
res_idxint数据块序列号，由服务端生成，从 1 递增。
nbestarray候选识别结果。
end_flagint是否最后一个数据块：0 否，1 是。
textstring语音识别结果，失败时为空。
confidenceint整句置信度，范围 0-100，值越大表示置信度越高。
speedint语速，范围 0-2000。
speed_labelstring语速标签：FAST、MEDIUM、SLOW。
volumeint音量，范围 0-100。
volume_labelstring音量标签：SILENT、XSOFT、SOFT、MEDIUM、LOUD、XLOUD。
wordsarray词级别识别结果，结构与 RESTful API 一致，包含 word、sos、eos、confidence。

响应结果示例

{
  "code": 90000,
  "message": "Success",
  "trace_id": "TRACE_ID",
  "data": {
    "res_idx": 1,
    "end_flag": 1,
    "nbest": ["你好标贝科技"],
    "text": "你好标贝科技",
    "confidence": 92,
    "words": []
  }
}

错误码

错误码说明解决方案
90000文本数据。正常读取识别结果。
90001检测到音频。正常。
90002未检测到音频，超过最大开始静音时长。检查音频有效长度，或调整最大开始静音时长参数。
30001HTTP 请求参数错误。检查请求参数和音频分包。
30002服务内部错误。保留 trace_id 并反馈排查。
30005语音质量问题。检查录音质量、噪声、音量和采样参数。
30006输入语音过长。确保单次语音不超过 60 秒。
