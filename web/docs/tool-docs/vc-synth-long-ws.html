定制声音合成 Websocket API

定制声音合成 Websocket API 适用于较长文本的流式合成。客户端建立 WebSocket 连接后发送合成参数，服务端分片返回 base64 编码的音频数据，最后通过 end_flag 标记任务结束。

功能介绍

  • 支持长连接流式返回音频，适合长文本或需要边合成边接收的场景。
  • 合成文本需要使用 UTF-8 编码后再进行 base64 编码。
  • 单次请求最多不超过 20000 个汉字。
  • 支持 16K、8K PCM 音频输出，以及语速、音量、音调、时间戳等参数。
  • voice_name 填写训练成功后的定制模型 modelId。

交互流程

  1. 创建应用并获取 client_id、client_secret。
  2. 调用授权服务获取 access_token。
  3. 建立 WebSocket 连接。
  4. 发送 JSON 请求，文本字段放在 tts_params.text，值为 base64 后的 UTF-8 文本。
  5. 持续接收响应分片，解码 data.audio_data 并按 idx 顺序写入音频文件或播放器。
  6. 收到 data.end_flag=1 后关闭连接并释放资源。

请求参数

参数名称类型是否必填说明
access_tokenstring是用户访问令牌。
versionstring是版本信息，当前为 1.0。
tts_paramsobject是合成参数对象，内部字段均按字符串传递，其中 text 必填并需 base64 编码。

tts_params 字段

参数名称类型是否必填说明
textstring是合成文本，UTF-8 编码后进行 base64 编码，单次请求最多不超过 20000 个汉字。
domainstring是应用领域编码，目前固定为 1。
languagestring是合成请求文本语言，中文及中英混合文本使用 ZH。
voice_namestring是模型名称，填写定制模型训练成功后返回的 modelId。
speedstring否语速，取值 0-9，支持浮点值，默认 5。
volumestring否音量，取值 0-9，仅支持整数，默认 5。
pitchstring否音调，取值 0-9，支持浮点值，默认 5。
audiotypestring否音频类型。4 返回 16K pcm，默认值；5 返回 8K pcm。
ratestring否采样率相关参数，按音频类型配合使用。
intervalstring否音子级时间戳开关：0 关闭，1 开启。
spectrumstring否高频频谱调节，取值 1-20，默认 1 表示不调整。
spectrum_8kstring否低频频谱调节，取值 0-20，默认 0，仅针对 8K 音频生效。
silencestring否标点静音时长：0 默认，1 句中标点停顿较短，2 句中标点停顿较长。

请求示例

{
  "access_token": "ACCESS_TOKEN",
  "version": "1.0",
  "tts_params": {
    "domain": "1",
    "interval": "1",
    "language": "ZH",
    "voice_name": "MODEL_ID",
    "audiotype": "4",
    "text": "5qCH6LSd56eR5oqA77yM5LiT5rOo5LqO5pm66IO96K+t6Z+z5oqA5pyv"
  }
}
import base64
import json
import websocket

uri = "wss://openapi.data-baker.com/tts_personal/wsapi"
text = "标贝科技，专注于智能语音技术"
payload = {
    "access_token": "ACCESS_TOKEN",
    "version": "1.0",
    "tts_params": {
        "domain": "1",
        "language": "ZH",
        "voice_name": "MODEL_ID",
        "audiotype": "4",
        "text": base64.b64encode(text.encode("utf-8")).decode("utf-8")
    }
}

audio = bytearray()
ws = websocket.create_connection(uri)
ws.send(json.dumps(payload))
while True:
    message = json.loads(ws.recv())
    if message.get("code") != 90000:
        print(message)
        break
    data = message.get("data") or {}
    if data.get("audio_data"):
        audio.extend(base64.b64decode(data["audio_data"]))
    if data.get("end_flag") == 1:
        break
ws.close()
open("result.pcm", "wb").write(audio)

响应结果

参数名称类型说明
codeint状态码。90000 表示成功；4xxxx 多为客户端参数错误；5xxxx 多为服务端内部错误。
messagestring状态描述或错误描述。
trace_idstring链路跟踪 ID，排查问题时可提供给技术支持。
data.idxint音频分片序号。
data.audio_datastringbase64 编码的音频分片数据。
data.audio_typestring返回音频类型。
data.intervalstring时间戳信息，仅开启 interval 时关注。
data.interval_xstring扩展时间戳信息，仅开启 interval 时关注。
data.end_flagint结束标记。1 表示本次合成结果已全部返回，可关闭连接。
