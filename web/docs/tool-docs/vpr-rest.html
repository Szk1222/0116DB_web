声纹识别 RESTful API

通过三段说话人音频完成声纹注册，再使用 1:1 或 1:N 接口进行身份验证和检索。

音频要求

  • 推荐音频时长约 10 秒，最短 1 秒，最长 30 秒。
  • 格式：PCM。
  • 采样率：16000Hz。
  • 位深：16bit。
  • 声道：单声道。
  • 请求中的音频需要先进行 Base64 编码。

鉴权与调用流程

  1. 在开放平台创建账号和应用，获取 client_id 与 client_secret。
  2. 调用访问令牌接口获取 access_token。
  3. 调用创建接口获取 registerId。
  4. 至少提交三段音频完成声纹注册。
  5. 根据业务需要调用 1:1 验证或 1:N 检索。

所有接口均使用 POST，请求头为 Content-Type: application/json。

创建声纹特征 ID

创建一个可用于注册声纹的 registerId。

curl -X POST \
  -H "Content-Type: application/json" \
  https://openapi.data-baker.com/vpr/createid \
  -d '{"access_token":"your_access_token"}'
{
  "err_msg": "SUCCESS",
  "log_id": "1637151763693260",
  "err_no": 90000,
  "registerid": "1760157933973465631"
}

声纹注册

使用同一个 registerId 至少提交三段音频。当某次注册失败时，需要重新提交，直到达到注册要求。

请求参数

参数类型必填说明
access_tokenString是访问令牌。
formatString是音频格式，例如 pcm。
audioString是Base64 编码后的音频数据。
registerIdString是创建声纹特征 ID 接口返回的 ID。
nameString是声纹关联名称。
scoreThresholdFloat是比对分数阈值，不能低于系统默认值。
 
{
  "access_token": "your_access_token",
  "format": "pcm",
  "audio": "BASE64_AUDIO",
  "registerId": "1760157933973465631",
  "name": "demo",
  "scoreThreshold": 65.0
}
{
  "err_msg": "SUCCESS",
  "log_id": "1637152591998223",
  "err_no": 90000,
  "suc_num": 1
}

声纹验证（1:1）

上传待验证音频，与指定的声纹特征进行比对，返回是否匹配和比对分数。

{
  "access_token": "your_access_token",
  "format": "pcm",
  "audio": "BASE64_AUDIO",
  "scoreThreshold": 60.0,
  "matchId": "register_id"
}
{
  "matchStatus": 0,
  "err_msg": "SUCCESS",
  "log_id": "1639473151396592",
  "err_no": 90000,
  "score": 1.5
}

matchStatus 为 1 表示比对成功，0 表示比对失败。

查询声纹状态

{
  "access_token": "your_access_token",
  "registerId": "register_id"
}
{
  "err_msg": "SUCCESS",
  "log_id": "1637152702700241",
  "err_no": 90000,
  "status": 3
}

status 为 3 表示注册成功，0 表示尚未注册完成。

删除声纹

传入 registerId 删除对应声纹。

curl -X POST \
  -H "Content-Type: application/json" \
  https://openapi.data-baker.com/vpr/delete \
  -d '{"access_token":"your_access_token","registerId":"register_id"}'
{
  "err_msg": "SUCCESS",
  "log_id": "1639473151396592",
  "err_no": 90000,
  "status": 1
}

声纹检索（1:N）

上传待检索音频，与声纹库中的全部特征进行比对并返回匹配列表。

请求参数

参数类型必填说明
access_tokenString是访问令牌。
formatString是音频格式，例如 pcm。
audioString是Base64 编码后的音频，最长 60 秒。
scoreThresholdFloat是比对分数阈值，系统默认值为 15.0，推荐使用 30.0。
listNumInt是返回的匹配条数。
vadInt否是否开启语音端点检测，1 开启，0 关闭，默认关闭。
 
{
  "access_token": "your_access_token",
  "format": "pcm",
  "audio": "BASE64_AUDIO",
  "scoreThreshold": 30.0,
  "listNum": 5
}
{
  "log_id": "1637153028866860",
  "err_msg": "SUCCESS",
  "matchList": [
    {"spkid": "3bc084c0-a0ea-4fe2-9b1b-358c74b21c8b", "score": 63.93, "name": "1"},
    {"spkid": "70532bab-0cce-4d23-af07-4f18bb94b928", "score": 61.93, "name": "2"}
  ],
  "err_no": 90000
}

错误码

错误码说明
90000成功。
10001 - 10003请求参数、请求体或请求头错误。
20001 - 20003数据库、资源或缓存服务错误。
30001 - 30005音频过长、过短、数据错误、调用次数或并发超限。
40001引擎内部错误。
50001 - 50002访问令牌校验失败或无效。
