法律声明及隐私政策

本政策说明平台如何收集、使用、存储、共享和保护用户信息，以及用户可以行使的相关权利。

适用范围与同意

  • 本政策适用于平台提供的网站、控制台、接口、SDK 和相关服务。
  • 使用服务或勾选同意本政策，即表示已阅读并理解相关内容。
  • 第三方产品或服务有独立隐私政策的，以相应第三方政策为准。

信息收集

  • 注册和联系信息：手机号、邮箱、联系人、职位、企业资料等。
  • 认证信息：为完成主体认证或服务开通所需的证明资料。
  • 设备与日志信息：设备型号、系统版本、浏览器信息、IP 地址、访问时间、操作记录和故障日志。
  • 业务数据：使用接口或 SDK 时提交的文本、音频、配置和调用结果。

信息使用

  • 用于创建账户、完成认证、提供技术服务、处理订单和发送必要通知。
  • 用于安全校验、异常检测、故障排查、服务统计和产品改进。
  • 在取得必要授权后，用于客户支持、服务沟通和产品介绍。
  • 超出原收集目的或合理关联范围使用时，会另行说明并取得必要同意。

信息共享与保护

  • 平台仅在提供服务所必要的范围内委托受托方处理信息，并要求其承担保密和安全义务。
  • 除获得授权、法律要求或为保护平台及用户权益所必要外，不会擅自公开披露用户信息。
  • 平台采取访问控制、加密、脱敏、备份、审计和安全应急措施保护信息。
  • 业务数据的合法来源、使用授权和内容安全由提交者负责。

用户权利

  • 可以查询、更正账户资料，或通过平台公布的渠道提交删除申请。
  • 可以撤回非必要信息的授权；撤回后可能影响依赖该信息的部分服务。
  • 可以对信息收集和使用提出疑问、投诉或建议，平台将在合理期限内回复。
