定制模型 iOS SDK

定制模型 iOS SDK 用于在 iOS 端完成声音复刻，包括噪声检测、朗读文本获取、录音、上传识别、提交训练、模型状态查询和合成体验。

下载与兼容

SDK 与示例 Demo 下载地址：https://github.com/data-baker/BakerIosSdks

  • 系统版本：iOS 8.0 及以上。
  • CPU 架构：arm64、arm64e、armv7、armv7s。
  • 权限配置：在 Info.plist 中添加 Privacy - Microphone Usage Description。

集成方式

通过 CocoaPods 集成：

pod 'DBAudioSDK/DBVoiceEngraverKit', 'SDK_VERSION'

SDK_VERSION 为实际接入版本号。接入后在业务文件中导入头文件：

#import "DBVoiceEngraverManager.h"
#import "DBVoiceDetectionUtil.h"

接入流程

  1. 实例化 DBVoiceDetectionUtil 并实现噪声检测代理。
  2. 初始化 DBVoiceEngraverManager，传入 clientId、clientSecret 和 queryId。
  3. 获取朗读文本列表，进入朗读录音页面。
  4. 按文本开始录音，结束后上传当前音频并接收识别结果。
  5. 全部文本录制完成后，提交训练并等待模型生成。
  6. 通过 queryId 或 modelId 查询训练状态。
  7. 训练成功后，将 modelId 作为合成接口或合成 SDK 的 voice_name。

噪声检测

录音前建议先检测环境噪声，并在 DBVoiceDetectionDelegate 中接收检测过程音量、检测结果和试听结束等回调。

代理方法说明
dbDetecting检测进行中，可用于展示实时音量。
dbDetectionResult检测完成，返回当前环境是否适合录音。
dbVoiceRecognizeError检测或识别过程中出现错误。
playToEnd试听音频播放完成。

初始化 SDK

[[DBVoiceEngraverManager sharedInstance] setupWithClientId:@"CLIENT_ID"
                                             clientSecret:@"CLIENT_SECRET"
                                                  queryId:@"QUERY_ID"
                                           SuccessHandler:^{
  // 初始化成功
} failureHander:^(DBErrorState errorState, NSString *message) {
  // 初始化失败
}];

如需切换用户标识，可调用：

[[DBVoiceEngraverManager sharedInstance] setupQueryId:@"QUERY_ID"];

朗读与录音

先获取朗读文本，再按文本开始录音。录音异常中断时，建议调用异常停止接口释放本次会话资源。

[[DBVoiceEngraverManager sharedInstance] getRecordTextArrayTextHandler:^(NSArray *textArray) {
  // 展示朗读文本
} failure:^(DBErrorState errorState, NSString *message) {
  // 获取失败
}];

[[DBVoiceEngraverManager sharedInstance] startRecordWithText:text
                                              failureHander:^(DBErrorState errorState, NSString *message) {
  // 开始录音失败
}];

[[DBVoiceEngraverManager sharedInstance] pauseRecord];
[[DBVoiceEngraverManager sharedInstance] unNormalStopRecordSeesionSuccessHandler:^{
  // 已释放异常会话
} failureHandler:^(DBErrorState errorState, NSString *message) {
  // 释放失败
}];

上传识别与提交训练

单条朗读结束后上传当前音频并接收识别结果；全部文本完成后提交模型训练。notifyUrl 需为外网可访问地址且不携带参数。

[[DBVoiceEngraverManager sharedInstance] uploadRecordVoiceRecogizeHandler:^(DBVoiceRecognizeModel *model) {
  // 当前音频识别结果
}];

[[DBVoiceEngraverManager sharedInstance] startModelTrainRecordVoiceWithPhoneNumber:@"13800000000"
                                                                         notifyUrl:@"https://example.com/voice/callback"
                                                                    successHandler:^(DBVoiceModel *model) {
  // 提交训练成功
} failureHander:^(DBErrorState errorState, NSString *message) {
  // 提交训练失败
}];

关键类与回调

类 / 回调说明

DBVoiceModel训练成功或查询返回的声音模型对象。
DBVoiceRecognizeModel单条录音上传后的识别结果对象。

体验合成

训练成功后，DBVoiceModel 中的 modelId 可作为 voice_name 用于短文本合成 RESTful API 或语音合成 iOS SDK。体验文本长度和并发限制请以当前授权与合成接口说明为准。
