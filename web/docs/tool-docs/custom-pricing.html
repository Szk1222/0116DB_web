试用版-测试授权规则变更说明

自2020年10月1日起，免费试用版规则调整为如下内容：

语音识别服务：
  • 一句话识别、实时语音识别每自然日内支持2个并发调用，每自然日用量不超500次， 免费试用期限为1个月。
  • 录音文件识别每自然日识别时长不超过2小时，免费试用期限为1个月。
语音合成服务：
  • 语音合成每自然日内支持2个并发调用，每自然日用量不超2000次，免费试用期限为1个月。
  • 长文本语音合成每自然日内支持2个并发调用，每自然日自然用量50000字符，试用期限为2周。
声音转换服务：
  • 声音转换每自然日内支持2个并发调用，每自然日用量不超200次，免费试用期限为1个月。

正式商用版-永久授权

  • 商用版按每自然日使用量计费，无免费额度，不使用则不产生费用。北京时间每日24 时，系统将自动对当日用量进行全量计算并计费，计费及服务调用量记录可联系我司技 术服务人员查询。
  • 开通商用版后，不可再次降配为试用版。（商用版降配试用版后，可用并发数将置为0， 服务将无法继续使用）
计费规则：
  • 按时长计费的，累加每次调用的语音时长（按秒向下取整。如本次发送的语音长度为 30.8秒，则记为30秒）。
  • 按次数计费的，返回失败的调用不计入次数。
  • 计费总额按照当日24时前总用量进行全量计费。
  • 语音合成的计费调用次数按照每次请求传入的字符数（UTF-8编码。1个汉字、英文字母、全半角标点符号均算1个有效字符）作为统计依据：100个字符内（含100个）记为1次计费调用；每超过100个字符增加1次计费调用，且1次请求最多传入300个字符。如，102个字符记为2次计费调用，201个字符记为3次计费调用，依此类推。

超额并发路数线路资费 超出采购额定线路，需要额外增加线路需求 并发数计算：并发数指同一个账号同时在处理的请求数。一般语音请求的处理都会延续一段时间。（例如，您新建一个语音合成请求，持续发送语音数据给服务端，这时并发数就是1；在该请求处理的同时，又新建了一个请求发送语音数据，这时服务端同时处理该账号的2个请求，并发数就变为2 ）
