定制模型 Android SDK

定制模型 Android SDK 用于在移动端完成声音复刻流程，包括环境噪声检测、获取朗读文本、录音、上传识别、提交训练、查询模型状态以及体验合成效果。

下载与依赖

SDK 与示例 Demo 下载地址：https://github.com/data-baker/BakerAndroidSdks

在项目根目录的 build.gradle 中加入 JitPack 仓库：

allprojects {
  repositories {
    maven { url 'https://jitpack.io' }
  }
}

在业务 Module 中加入依赖：

dependencies {
  implementation 'com.github.data-baker.BakerAndroidSdks:engravelib:2.0.13'
  implementation 'com.squareup.okhttp3:okhttp:4.2.2'
  implementation 'com.google.code.gson:gson:2.8.6'
  implementation 'com.kailashdabhi:om-recorder:1.1.5'
}

权限配置

在 AndroidManifest.xml 中声明网络、录音和存储权限；Android 6.0 及以上还需要动态申请录音和存储权限。

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

如项目需要允许明文网络访问，在 application 节点增加：

android:usesCleartextTraffic="true"

接入流程

  1. 初始化 SDK，传入 clientId、clientSecret 和用于区分用户的 queryID。
  2. 动态申请 RECORD_AUDIO 等权限，并进行环境噪声检测。
  3. 获取朗读文本列表，引导用户逐条朗读。
  4. 获取 mouldId，开始录音并上传每条朗读音频。
  5. 全部音频上传完成后，调用训练接口提交手机号码和回调地址。
  6. 通过 queryId 或 mouldId 查询模型状态；训练成功后得到 modelId。
  7. 将 modelId 作为合成接口或合成 SDK 中的 voice_name 使用。

初始化 SDK

BakerVoiceEngraver.getInstance().initSDK(
    context,
    "CLIENT_ID",
    "CLIENT_SECRET",
    "QUERY_ID"
);

如果初始化后需要切换用户标识，可在获取模型前调用：

BakerVoiceEngraver.getInstance().setQueryId("QUERY_ID");

噪声检测与录音

录音前建议先检测环境噪声。检测过程约 3 秒，最终音量值大于 70 时建议提示用户更换安静环境后重新录制。

BakerVoiceEngraver.getInstance().setDetectCallback(detectCallback);
BakerVoiceEngraver.getInstance().startDBDetection();

获取朗读文本并开始录音：

BakerVoiceEngraver.getInstance().setContentTextCallback(contentTextCallback);
BakerVoiceEngraver.getInstance().getTextList();

String mouldId = BakerVoiceEngraver.getInstance().getVoiceMouldId();
BakerVoiceEngraver.getInstance().setRecordCallback(recordCallback);
int startCode = BakerVoiceEngraver.getInstance().startRecord(contentText);
返回值说明
0mouldId 为空，需先获取声音复刻任务 ID。
1没有录音权限。
2开始录音成功。

上传与提交训练

每条朗读结束后上传当前音频；如上传失败，可调用重传接口。

BakerVoiceEngraver.getInstance().setUploadRecordsCallback(uploadRecordsCallback);
BakerVoiceEngraver.getInstance().uploadRecords(contentText);
BakerVoiceEngraver.getInstance().reUploadRecords(contentText);

全部文本完成后，提交模型训练。phone 与 notifyUrl 均可按业务需要传入；notifyUrl 需为外网可访问地址且不携带参数。

String mouldId = BakerVoiceEngraver.getInstance()
    .finishRecords("13800000000", "https://example.com/voice/callback");

如用户中途退出，应调用 recordInterrupt() 释放本次录音和模型任务资源。

查询模型状态

BakerVoiceEngraver.getInstance().setMouldCallback(mouldCallback);
BakerVoiceEngraver.getInstance().getMouldList(1, 20, "QUERY_ID");
BakerVoiceEngraver.getInstance().getMouldInfo("MOULD_ID");
字段说明
modelId训练成功后生成的声音模型 ID，可作为 voice_name 使用。
modelStatus模型状态：1 默认、2 录制中、3 开启训练失败、4 训练中、5 训练失败、6 训练成功。
statusName模型状态展示名称。

关键类与回调

体验合成

模型训练成功后，可通过两种方式体验合成效果：一是调用短文本合成 RESTful API 并把 modelId 作为 voice_name；二是在语音合成 Android SDK 中使用同一模型 ID。体验接口通常限制文本长度，正式项目请以当前授权和接口说明为准。
