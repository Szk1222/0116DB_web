长语音识别 Android SDK

长语音识别 Android SDK 用于实时长语音流识别，支持 SDK 调用麦克风录音识别，也支持接收音频字节流并上传识别。单次识别时长不超过 3 小时。

下载安装

SDK 及示例 Demo 下载地址：https://github.com/data-baker/BakerAndroidSdks

将以下 AAR 包复制到主 Module 的 libs 目录：

bakerlongtimeasr-release.aar
basecomponent-release.aar
bakerhttp-release.aar

Android Studio 集成

dependencies {
  implementation fileTree(dir: 'libs', include: ['*.aar'])
  implementation 'com.squareup.okhttp3:okhttp:4.2.2'
  implementation 'com.google.code.gson:gson:2.8.6'
}

SDK 内使用 OkHttp 和 Gson，如果工程中已有对应依赖，无需重复添加。OkHttp 请使用 4.x 版本。

在 AndroidManifest.xml 中声明网络和录音相关权限；Android 6.0 及以上需要动态申请 RECORD_AUDIO 权限。

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />

如需允许明文网络访问，在 application 节点增加：

android:usesCleartextTraffic="true"

SDK 关键类

类名说明
LongTimeAsr长语音识别业务处理类，全局只需一个实例。
LongTimeAsrCallBack实时识别结果、状态和错误信息回调类。回调方法运行在子线程。
LongTimeAsrResponse长语音识别结果模型。

初始化 SDK

实例化 LongTimeAsr：

LongTimeAsr longTimeAsr = new LongTimeAsr();

调用公共识别服务时，传入授权邮件中的 clientId 与 clientSecret：

longTimeAsr.initSdk(context, clientId, clientSecret, longTimeAsrCallBack);

私有化部署时，需要设置识别服务器地址：

longTimeAsr.initSdk(context, longTimeAsrCallBack);
longTimeAsr.setUrl("ws://xxxx");

识别场景

麦克风录音识别

  1. 应用先取得录音权限。
  2. 通过 LongTimeAsr 实例设置识别参数。
  3. 调用 longTimeAsr.startAsr() 开始识别。
  4. 在 LongTimeAsrCallBack 回调中接收状态、识别结果或错误信息。
  5. 调用 longTimeAsr.stopAsr() 结束识别。

音频字节流识别

  1. 调用 longTimeAsr.start() 通知 SDK 准备识别。
  2. 在 onReady() 回调后，多次调用 longTimeAsr.send(byte[] data) 输入待识别音频字节流。
  3. 单次数据建议固定为 5120 字节，最后一片可以为其他长度。
  4. 前后两次 send 的间隔不要超过 60 秒；私有化部署以服务端配置为准。
  5. 调用 longTimeAsr.end() 结束识别。
  6. 确定不再使用识别后，调用 longTimeAsr.release() 释放 SDK 资源。

参数与方法

方法是否必填说明
initSdk是初始化 SDK，设置授权信息和回调。
setUrl否设置识别服务器地址，仅私有化部署需要。
setSampleRate否设置采样率，支持 16000、8000，默认 16000。
setAddPct否设置是否返回标点，默认 true。
setDomain否设置模型名称，默认 common。
setAudioFormat否输入字节流识别时设置音频编码格式，支持 pcm、wav。
setHotwordid否配置热词组 ID。
setDiylmid否配置 ASR 个性化模型 ID。
startAsr场景相关启动麦克风录音识别。
stopAsr场景相关结束麦克风录音识别。
start场景相关启动字节流识别任务。
send(byte[] data)场景相关发送音频字节流分片。
end场景相关结束字节流识别任务。
release否释放 SDK 资源。

LongTimeAsrCallBack 回调

方法说明
onReady()授权验证通过且与服务器连接成功，识别准备就绪。
onRecording(LongTimeAsrResponse response)实时识别结果回调，返回完整响应模型。
onRecording(String result, boolean sentenceEnd, boolean endFlag)实时识别文本回调。sentenceEnd=true 表示当前句最终结果，endFlag=true 表示全部识别结束。
onVolume(int volume)音量分贝回调，范围 0-100。
onError(String code, String errorMessage)识别出错回调。一旦出现错误，本次识别任务中断。

LongTimeAsrResponse 参数

字段类型说明
codeint错误码，9000 表示包含有效识别数据。
messagestring错误描述。
trace_idstring任务 ID，用于定位错误和日志。
asr_textstring识别结果文本。
sentence_idint句子 ID，从 1 递增。
sentence_endboolean当前句子是否结束。
end_flagint是否最后一个数据块，0 否，1 是。
sosfloat句子在音频中的开始时间点，单位秒。
eosfloat句子在音频中的结束时间点，单位秒。
confidenceint整句置信度，范围 0-100。
speedint语速，范围 0-2000。
speed_labelstring语速标签：FAST、MEDIUM、SLOW。
volumeint音量，范围 0-100。
volume_labelstring音量标签：SILENT、XSOFT、SOFT、MEDIUM、LOUD、XLOUD。
wordsarray词级别识别结果，包含 confidence、sos、eos、word。

40007idx 顺序错误检查音频分片序号。
