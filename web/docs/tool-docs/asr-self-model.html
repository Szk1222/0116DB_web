自学习-个性化模型

功能介绍

在语音识别ASR服务中，如使用者在专有领域积累了丰富的文本数据，通过标贝科技强大的算法团队自主研发的ASR自学习引擎，使用者可自主完成个性化语言模型配置及训练，进一步提高专有领域场景下的语音识别准确率，达到定制训练、自助优化的效果。

使用限制

  • 1、保存到生效的时间：约5~20分钟后生效。
  • 2、单个应用-语音识别服务下最多可创建5个个性化语言模型，每个模型上传文件格式（不超过12MB，UTF-8编码的txt文件，每行一段话或一个词且字数不大于150个字，以回车键区分，只能包含简体汉字或英文字母）。
  • 3、应用服务：一句话识别、长文本识别、录音文件识别。
  • 4、支持语言类型：中文普通话、粤语、英文。
  • 5、创建修改：控制台方式。
  • 6、热词支持采样率模型：8K（通用电话客服）、16K采样率。
  • 7、控制台完成个性化模型添加并【已生效】后，后续开发者在请求语音识别服务时，通过模型id的传参可直接使用此个性化模型，达到提升优化的效果。

特别注意

  • 1、上传文本只能包含简体汉字或英文字母，UTF-8格式，中文语言类型中数字需用汉字代替，英文语言类型中数字需用英文代替，英文字母用半角小写。例如：
    十月二十六号
    百分之八十
    三点一四
    vip
    nba
  • 2、训练文本数据为使用者在专有领域和行业积累的文本数据，数据越接近真实使用场景，识别准确率越高。

使用方法

  • 1、 登录开放平台-创建应用。
  • 2、 点击左侧导航栏，选择语音识别下【自学习工具】，进入热词页面,点击上方切换按钮【个性化模型】进入个性化模型页面。
  • 3、 点击【新增模型】上传训练文本txt文件，进行个性化模型添加。
  • 4、【保存并发布后】，约5~20分钟后模型完成训练，状态为【已生效】。
  • 5、 获取个性化模型id，通过语音识别API或SDK识别调用，测试效果。
