自学习 - 个性化模型

个性化模型用于通过业务文本语料训练专有语言模型，提升特定领域、行业或场景下的语音识别准确率。模型训练完成并生效后，在识别请求中传入模型 ID 即可使用。

功能介绍

当业务场景中积累了大量专有文本数据时，可使用 ASR 自学习引擎完成个性化语言模型配置和训练。相比热词，个性化模型更适合较长文本、句式表达、专业领域语料等整体语言习惯优化。

训练文本越接近真实使用场景，识别效果通常越好。

使用限制

项目说明
生效时间保存发布后约 5-20 分钟生效。
模型数量单个应用的语音识别服务下最多可创建 5 个个性化语言模型。
文件大小每个模型上传文件不超过 12MB。
文件编码UTF-8 编码的 txt 文件。
文本格式每行一段话或一个词，以回车键区分。
单行长度每行字数不大于 150 个字。
字符范围只能包含简体汉字或英文字母。
适用服务一句话识别、实时长语音识别、录音文件识别。
语言类型中文普通话、粤语、英文。
采样率模型8K、16K 采样率。
创建方式通过开放平台控制台创建和修改。

特别注意

  • 上传文本只能包含简体汉字或英文字母，并使用 UTF-8 编码。
  • 中文语言类型中的数字需要用汉字代替，例如 10月26号 写作 十月二十六号。
  • 百分数、小数等也建议按自然读法书写，例如 80% 写作 百分之八十，3.14 写作 三点一四。
  • 英文语言类型中的英文字母使用半角小写，例如 vip、nba。
  • 训练文本应来自真实业务场景，避免堆叠无关文本。

使用方法

  1. 登录开放平台并创建应用。
  2. 进入语音识别下的自学习工具页面。
  3. 切换到个性化模型页面。
  4. 点击新增模型，上传训练文本 TXT 文件。
  5. 保存并发布后等待训练完成，模型状态变为已生效。
  6. 获取个性化模型 ID。
  7. 调用语音识别 API 或 SDK 时传入该模型 ID，测试识别效果。

识别调用传参

控制台完成个性化模型添加并生效后，在后续语音识别请求中传入 diylmid 即可使用该模型。

参数类型说明
diylmidstringASR 个性化模型 ID。适用于一句话识别、实时长语音识别、录音文件识别等支持个性化模型的请求。
{
  "asr_params": {
    "audio_format": "wav",
    "sample_rate": 16000,
    "diylmid": "MODEL_ID"
  }
}
