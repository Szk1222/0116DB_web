声音转换 Websocket API

声音转换 Websocket API 面向实时声音转换场景。客户端以音频流形式输入原始声音，服务端以流式方式返回转换后的音频，可实现边说话边转换。

音频要求

  • 音频编码：pcm。
  • 采样率 / 位深：16000Hz / 16bit。
  • 声道：单声道。
  • 语言：中文普通话。
  • 有效时长：不超过 180 分钟。

服务地址

访问类型说明URLHost
外网访问WebSocket 协议wss://openapi.data-baker.com/ws/voice_conversionopenapi.data-baker.com

使用流程

  1. 创建账号和应用，获取 client_id 与 client_secret。
  2. 调用授权服务获取 access_token。
  3. 建立 WebSocket 连接。
  4. 按数据包格式实时发送待转换音频。
  5. 接收转换后的音频数据。
  6. 最后一包发送或接收完成后关闭连接。

请求参数

参数名参数格式是否必填说明
access_tokenstring是通过 client_id、client_secret 调用授权服务获得。
voice_namestring是目标声音参数，例如 Vc_jiaojiao。
lastpkgbool是是否为最后一包。发送最后一包数据时设置为 true，表示输入完成。
enable_vadbool否true 表示启动服务端 VAD，默认 false。开启后会根据输入音频检测并过滤环境噪音。
align_inputbool否true 表示输出音频与输入音频对齐，默认 false。开启 VAD 时可保留静音部分。

WS 数据包格式

每个二进制数据包由三部分组成：

  1. HEAD：4 字节大端 32 位整数，表示第二部分 JSON 字符串的字节长度。
  2. JSON：请求参数 JSON 字符串。
  3. Audio：音频二进制数据；若数据包不包含音频，该部分可以为空。
// length 转 byte[]
int32_t length = 123;

Python 示例

import json
import requests
import websocket

def make_packet(params, audio):
    body = json.dumps(params).encode("utf-8")
    return len(body).to_bytes(4, byteorder="big") + body + audio

params = {
    "access_token": "ACCESS_TOKEN",
    "voice_name": "Vc_jiaojiao",
    "enable_vad": True,
    "align_input": True,
    "lastpkg": False
}

ws = websocket.create_connection("wss://openapi.data-baker.com/ws/voice_conversion")
with open("origin.pcm", "rb") as f:
    chunks = iter(lambda: f.read(32000), b"")
    for chunk in chunks:
        params["lastpkg"] = len(chunk) < 32000
        ws.send_binary(make_packet(params, chunk))

converted = bytearray()
while True:
    message = ws.recv()
    length = int.from_bytes(message[:4], byteorder="big")
    result = json.loads(message[4:4 + length].decode("utf-8"))
    converted.extend(message[4 + length:])
    if result.get("lastpkg") or result.get("errcode") != 0:
        break
ws.close()
open("result.pcm", "wb").write(converted)

响应结果

参数名类型说明
errcodeint0 表示当前包处理成功，非 0 表示出现错误。
errmsgstring错误信息。
traceidstring链路追踪 ID，可用于问题排查。
lastpkgbool是否为最后一包。为 true 时，表示转换数据已返回完毕。
音频数据binaryJSON 之后的二进制部分为转换后的音频数据。
