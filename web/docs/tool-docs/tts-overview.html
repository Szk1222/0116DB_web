语音合成接口说明

功能说明

  • 支持设置合成音频的格式: pcm,wav,alaw,ulaw,mp3
  • 支持设置合成音频的采样率: 8000Hz,16000Hz, 24000Hz
  • 支持设置多种发音人
  • 支持设置音量、语速、语调
  • 支持返回时间戳信息
  • 支持设置多种语言:中文(zh)，英文(eng)，粤语(cat)，四川话(sch)，天津话(tjh)，台湾话(tai)，韩语(kr)，巴葡语(bra)，日语(jp)，西班牙西语(ESP)，墨西哥西语(MEX)，维吾尔语(UYG)
    • 纯中文及中英混language 参数设置language=zh
    • 英文language参数设置language=eng
    • 粤语language参数设置language=cat
    • 四川话language参数设置language=sch
    • 天津话language参数设置language=tjh
    • 台湾话language参数设置language=tai
    • 韩语language参数设置language=kr
    • 巴葡语language参数设置language=bra
    • 日语language参数设置language=jp
    • 西班牙西语language参数设置language=ESP
    • 墨西哥西语language参数设置language=MEX
    • 维吾尔语language参数设置language=UYG

服务地址

  • Restful api: https://openapi.data-baker.com/tts?
  • Websocket api: wss://openapi.data-baker.com/tts/wsapi?
