定制声音合成 RESTful API

定制声音合成 RESTful API 用于调用声音复刻训练后的音色模型进行短文本合成。接入方式与在线合成类似，核心差异是 voice_name 需要填写定制模型训练成功后返回的 modelId。

功能介绍

  • 支持 HTTPS GET 和 POST 请求。
  • 支持返回 pcm、wav、mp3、alaw、ulaw 等音频格式。
  • 支持设置音量、语速、语调、音子级时间戳和标点静音时长。
  • 当前复刻音色合成文本语言按中文及中英混合文本接入。
  • 支持普通音质、精品音质等声音模型类型，具体以模型授权为准。

使用流程

  1. 在开放平台创建账号和应用，获取 client_id 与 client_secret。
  2. 调用授权服务获取 access_token。
  3. 准备待合成文本，并确认定制模型已训练成功。
  4. 请求 /tts_personal，将模型 ID 填入 voice_name。
  5. 根据响应头 Content-Type 判断请求是否成功：以 audio/ 开头表示返回音频；application/json 表示返回错误信息。

请求参数

参数名称是否必填说明
text是合成文本，UTF-8 编码。单次 GET 或 POST 请求最多不超过 300 个汉字。
access_token是用户访问令牌，通过 client_id、client_secret 调用授权服务获得。
domain是应用领域编码，目前固定为 1。
language是合成文本语言，中文及中英混合文本使用 ZH 或 zh。
voice_name是模型名称，填写定制模型训练成功后返回的 modelId。
speed否语速，取值 0-9，支持浮点值，默认 5。
volume否音量，取值 0-9，仅支持整数，默认 5。
pitch否音调，取值 0-9，默认 5。
audiotype否音频类型。常用值：3 为 16K mp3，4 为 16K pcm，5 为 8K pcm，6 为 16K wav，7 为 8K alaw，8 为 8K ulaw，9 可配合 rate=1 返回 8K mp3。
rate否采样率或码率相关参数。示例：audiotype=6&rate=1 返回 8K wav。
spectrum否高频频谱调节，取值 1-20，默认 1 表示不调整；值越大高频能量增强越多。
spectrum_8k否低频频谱调节，取值 0-20，默认 0，仅针对 audiotype=5 的 8K 音频生效。
interval否音子级时间戳开关：0 关闭，1 开启。
silence否标点静音时长：0 默认，1 句中标点停顿较短，2 句中标点停顿较长。

请求示例

curl -X POST "https://openapi.data-baker.com/tts_personal" \
  -d "access_token=ACCESS_TOKEN" \
  -d "domain=1" \
  -d "language=ZH" \
  -d "voice_name=MODEL_ID" \
  -d "text=欢迎使用标贝定制声音合成服务" \
  -d "audiotype=6" \
  --output result.wav
import requests

url = "https://openapi.data-baker.com/tts_personal"
data = {
    "access_token": "ACCESS_TOKEN",
    "domain": "1",
    "language": "ZH",
    "voice_name": "MODEL_ID",
    "text": "欢迎使用标贝定制声音合成服务",
    "audiotype": "6",
    "speed": "5",
    "volume": "5",
    "pitch": "5"
}

response = requests.post(url, data=data)
content_type = response.headers.get("Content-Type", "")
if content_type.startswith("audio/"):
    open("result.wav", "wb").write(response.content)
else:
    print(response.text)

响应结果

  • 合成成功时，响应体为音频二进制数据。
  • 合成失败时，响应头通常为 Content-Type: application/json，响应体为错误 JSON。
  • 当 interval=1 时，响应头会增加 interval-info，用于返回音子边界时间戳。
示例说明
audiotype=3返回 16K mp3，Content-Type: audio/mp3。
audiotype=4返回 16K pcm，Content-Type: audio/pcm。
audiotype=5返回 8K pcm，Content-Type: audio/pcm。
audiotype=6返回 16K wav，Content-Type: audio/wav。
audiotype=6&rate=1返回 8K wav，Content-Type: audio/wav。
audiotype=7返回 8K alaw，Content-Type: audio/alaw。
audiotype=8返回 8K ulaw，Content-Type: audio/ulaw。
audiotype=9&rate=1返回 8K mp3，Content-Type: audio/mp3。
