定制模型 RESTful API

定制模型 RESTful API 用于提交声音复刻训练任务。接口接收多段复刻音频和回调地址，初步校验成功后返回 modelId，并异步完成模型训练。

功能介绍

  • 支持上传 wav、pcm 音频文件。
  • 音频采样率要求 16000Hz，位深 16bits，单声道。
  • 支持中文声音复刻训练。
  • 有效音频时长建议不小于 3 分钟；实际会结合识别出的字数进行判定。
  • 训练结果通过 notifyUrl 异步回调返回。

请求参数

参数名称类型是否必填说明
access_tokenstring是通过 client_id、client_secret 调用授权服务获得。
originFilesMultipartFile[]是音频列表。格式为 pcm 或 wav，采样率 16000Hz，位深 16bits，单声道。
notifyUrlstring是用于接收训练结果的回调地址，必须外网可访问，不能携带参数。
mobilestring否手机号，用于接收短信提醒。正式项目中可按业务需要决定是否传入。

请求示例

import json
import requests

url = "https://openapi.data-baker.com/gramophone/v1/submit"
data = {
    "access_token": "ACCESS_TOKEN",
    "notifyUrl": "https://example.com/voice/callback"
}
files = [
    ("originFiles", ("101.wav", open("101.wav", "rb"), "audio/wav")),
    ("originFiles", ("201.wav", open("201.wav", "rb"), "audio/wav")),
    ("originFiles", ("301.wav", open("301.wav", "rb"), "audio/wav"))
]

response = requests.post(url, data=data, files=files)
print(json.dumps(response.json(), ensure_ascii=False, indent=2))

响应结果

接口收到请求后会先进行参数校验并立即返回。校验成功后进入异步训练和回调流程；校验失败时返回错误码并放弃本次训练。

字段类型说明
codestring请求结果码，20000 表示请求成功。
data.modelIdstring声音模型 ID。训练成功后可作为 voice_name 调用语音合成。
messagestring请求结果描述。

回调说明

训练进度或结果会通过 notifyUrl 回调。请求体中包含 modelId、modelStatus 和 reason 字段；modelStatus=success 表示训练成功，modelStatus=fail 表示训练失败。

建议回调服务收到请求后提取业务所需字段，并在响应体中返回固定字符串 SUCCESSOK。旧站文档标注：回调失败时会每隔 5 秒重试一次，最多重试 4 次，该策略可能调整。

from flask import Flask, request

app = Flask(__name__)

@app.route("/voice/callback", methods=["POST"])
def callback():
    payload = request.get_json(force=True)
    model_id = payload.get("modelId")
    status = payload.get("modelStatus")
    reason = payload.get("reason")
    print(model_id, status, reason)
    return "SUCCESSOK"

错误码

错误码含义处理建议
20000请求成功保存返回的 modelId 并等待回调。
30000鉴权错误，access_token 不正确或已失效重新获取 Token。
30008授权禁用检查服务授权。
30009授权到期续期或重新开通服务。
30010调用次数超过限制检查用量和配额。
30013授权不支持声音复刻确认应用已开通声音复刻能力。
40000参数获取失败或未传输检查必填参数。
40002提交次数已达到最大限制减少重复提交或联系服务人员。
40003接口请在有效期内使用检查接口有效期。
