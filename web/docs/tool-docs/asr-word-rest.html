一句话识别 RESTful API

一句话识别 RESTful API 用于识别不超过 60 秒的短语音，适用于语音交互、控制口令、对话聊天等场景。请求体直接上传二进制音频数据，接口返回 JSON 格式识别结果。

功能介绍

  • 时长限制：60 秒以内。
  • 支持音频格式：wav、pcm。
  • 音频采样率：8000Hz、16000Hz。
  • 位深：16bits。
  • 声道：单声道。

使用方法

  1. 创建账号和应用，在开放平台应用服务中获取 client_id 与 client_secret。
  2. 调用授权服务获取 access_token。
  3. 按请求参数说明发送识别请求，请求体为二进制音频数据。
  4. 接收 JSON 响应，识别文本在 text 字段中。

服务地址

访问类型说明URLHost
外网访问支持中文普通话、中英自由说、英文、粤语、维语。https://openapi.data-baker.com/asr/api?openapi.data-baker.com

请求参数

请求方法为 POST，Header 中传入鉴权与识别参数，请求体为音频二进制数据。

参数名称类型是否必填说明
access_tokenstring是通过 client_id、client_secret 调用授权服务获得。
audio_formatstring是音频编码格式，支持 wav、pcm。
sample_rateinteger是音频采样率，支持 8000、16000。
domainstring否模型名称。16k 支持 common、cn-en-mixed、english、cantonese、uighur；8k 支持 kefu。
add_pctboolean否是否添加标点：true 添加，false 不添加。
hotwordidstring否配置的热词组 ID。
diylmidstring否ASR 个性化模型 ID。
enable_itnboolean否中文数字转阿拉伯数字，仅支持 3 位及以上数字串：true 开启，false 关闭。

请求示例

import json
import requests

url = "https://openapi.data-baker.com/asr/api?"
headers = {
    "access_token": "ACCESS_TOKEN",
    "audio_format": "wav",
    "sample_rate": "16000",
    "add_pct": "true"
}

with open("test.wav", "rb") as f:
    audio = f.read()

response = requests.post(url, data=audio, headers=headers)
result = response.json()
print(result.get("text"))

响应结果参数

字段名类型描述
trace_idstring任务 ID。遇到问题时可反馈该 ID 用于排查。
codeint请求结果码，成功为 20000。
sidstring会话 ID。
textstring语音识别结果，失败时为空。
infostring任务结果描述，请求失败时可根据该字段分析问题。
confidenceint整句置信度，范围 0-100，值越大表示置信度越高。
speedint语速，范围 0-2000。
speed_labelstring语速标签：FAST、MEDIUM、SLOW。
volumeint音量，范围 0-100。
volume_labelstring音量标签：SILENT、XSOFT、SOFT、MEDIUM、LOUD、XLOUD。
wordsarray词级别识别结果。

words 内部结构

字段名描述
confidence词置信度，范围 0-1，值越大表示置信度越高。
sos词在音频中的绝对开始时间点，单位秒。
eos词在音频中的绝对结束时间点，单位秒。
word识别出的词。

错误码

错误码说明处理建议
20000请求成功。正常读取 text 等返回字段。
30001HTTP 请求参数错误。检查 Header 参数、音频格式和请求体。
30002服务内部错误。保留 trace_id 并反馈排查。
30005语音质量问题。检查录音质量、噪声、音量和采样参数。
30006输入语音过长。确保单次语音不超过 60 秒。
40001无效的 token。重新获取并传入有效 access_token。
40002无效的头部参数或未授权。检查应用权限和 Header 参数。
40005不支持的 audio_format。确认音频格式为接口支持的 wav 或 pcm。
