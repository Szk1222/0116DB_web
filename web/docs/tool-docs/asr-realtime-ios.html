长语音识别 iOS SDK

长语音识别 iOS SDK 用于实时长语音流识别，支持 SDK 调用设备麦克风录音识别，也支持接收音频字节流并上传识别。单次识别时长不超过 3 小时。

下载安装

SDK 及示例 Demo 下载地址：https://github.com/data-baker/BakerIosSdks

  • 项目说明：bakerIosSdks 是标贝科技语音相关的 iOS SDK 服务，长语音识别使用 DBLongASRKit。
  • 兼容系统：iOS 9.0 及以上。
  • 硬件架构：arm64、i386。
  • 权限说明：需要 Privacy - Microphone Usage Description 麦克风权限，并确保应用可访问网络。

集成说明

通过 CocoaPods 集成：

pod 'DBAudioSDK/DBLongASRKit'

可通过 pod search 查询并更新到需要的版本。也可以手动下载项目文件，并导入长语音识别相关代码，核心文件包括 DBFASRClient、DBResponseModel 和长语音响应模型。

SDK 关键类

类名说明
DBFASRClient长语音识别业务处理类，全局只需一个实例。
DBFASRClientDelegate实时识别结果、状态和错误信息回调协议。
DBLongResponseModel长语音识别结果模型。

初始化 SDK

实例化 DBFASRClient：

DBFASRClient *longTimeAsr = [DBFASRClient shareInstance];

调用公共识别服务时，传入授权邮件中的 clientId 与 clientSecret：

[longTimeAsr setupClientId:clientID clientSecret:clientSecret];

私有化部署时，设置识别服务器地址：

[longTimeAsr setupURL:privateServerUrl];

识别场景

麦克风录音识别

  1. 应用先取得录音权限。
  2. 通过 longTimeAsr 实例设置识别参数。
  3. 调用 [longTimeAsr startLongASR] 开始识别。
  4. 在 DBFASRClientDelegate 回调中接收状态、识别结果或错误信息。
  5. 调用 [longTimeAsr endLongASR] 结束识别。

音频字节流识别

  1. 调用 [longTimeAsr startLongASR] 通知 SDK 准备识别。
  2. 在 onReady 回调后，多次调用 [longTimeAsr websocketPostData:data] 输入待识别音频字节流。
  3. 单次数据建议固定为 5120 字节，最后一片可以为其他长度。
  4. 前后两次 websocketPostData: 的间隔不要超过 60 秒；私有化部署以服务端配置为准。
  5. 调用 [longTimeAsr endLongASR] 结束识别并释放本次任务。

参数与方法

方法 / 参数是否必填说明
setupClientId:clientSecret:是初始化 SDK 并设置授权信息。
setupURL:否设置识别服务器地址，仅私有化部署需要。
setSampleRate否设置采样率，支持 16000、8000，默认 16000。
setAddPct否设置是否返回标点，默认 true。
setDomain否设置模型名称，默认 common。
setAudioFormat否输入字节流识别时设置音频编码格式，支持 pcm、wav。
setHotwordid否配置热词组 ID。
setDiylmid否配置 ASR 个性化模型 ID。
startLongASR场景相关开始长语音识别。
websocketPostData:场景相关发送音频字节流分片。
endLongASR场景相关结束长语音识别并释放本次任务。

DBFASRClientDelegate 回调

方法说明
- (void)onReady授权验证通过且与服务器连接成功，识别准备就绪。
- (void)identifyTheCallback:(NSString *)message sentenceEnd:(BOOL)sentenceEnd实时识别文本回调。识别过程中可能多次返回，sentenceEnd=true 时表示当前句最终结果。
- (void)onError:(NSInteger)code message:(NSString *)message识别出错回调。一旦出现错误，本次识别任务中断。
- (void)resultTraceId:(NSString *)traceId返回每句话识别的 TraceID，用于问题追踪。
- (void)onResult:(DBLongResponseModel *)model返回完整长语音识别数据模型。

响应结果结构

字段类型说明
codeint错误码，9000 表示包含有效识别数据。
messagestring错误描述。
trace_idstring任务 ID，用于定位错误和日志。
asr_textstring识别结果文本。
sentence_idint句子 ID，从 1 递增。
sentence_endboolean当前句子是否结束。
end_flagint是否最后一个数据块，0 否，1 是。
sosfloat句子在音频中的开始时间点，单位秒。
eosfloat句子在音频中的结束时间点，单位秒。
confidenceint整句置信度，范围 0-100。
speedint语速，范围 0-2000。
speed_labelstring语速标签：FAST、MEDIUM、SLOW。
volumeint音量，范围 0-100。
volume_labelstring音量标签：SILENT、XSOFT、SOFT、MEDIUM、LOUD、XLOUD。
bWordsarray词级别识别结果，包含 confidence、sos、eos、word。
